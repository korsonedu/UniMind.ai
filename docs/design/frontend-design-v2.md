# UniMind 前端设计规范 v2

讨论稿，更新日期：2026 年 10 月 11 日。

原生工具感、应用框架、ELO 展示方式和靛蓝主色已确认。共享设计变量、应用导航、小宇和课程工作区已开始应用本稿，最终一起审阅整体效果。其他业务页面的专用组件继续按本稿逐步整理。

## 已确认的设计方向

采用原生工具感：安静、紧凑、精确，内容占主导，适合长时间学习与工作。

参考 Codex 的工作区组织方式，以及苹果应用对层级、对齐、控件状态和反馈一致性的处理。UniMind 保留自己的品牌与功能，不复制参考界面的视觉细节。具体尺寸为 UniMind 的产品选择。

高屏效比通过减少重复导航、合理利用宽度和紧密组织相关信息实现。不同信息组之间保留明确距离，正文保持可读性。装饰、徽标、阴影和动效均须有明确用途。

## 已确认的应用框架

| 区域 | 标准 |
| --- | --- |
| 功能导航 | 桌面宽度 64px，沿用功能入口。统一图标尺寸，悬停或键盘聚焦显示名称，当前页面使用浅背景标识。 |
| 上下文目录 | 小宇与课程默认宽度 208px，可见范围 200～320px；低于最小值以 220ms 收拢、140ms 淡出隐藏，保留展开按钮。共用拖动与键盘规则，避免极窄的目录状态。 |
| 工作区顶部操作 | 约 48px 的控件区域融入主内容，取消横向分割线和左上角重复标题。桌面不独占一整行，右上角保留必要操作、ELO、通知与账户入口，内容按实际控件范围避让。 |
| 主内容 | 功能 sidebar 外的全部区域作为一整块圆角面板，对话目录、课程目录与右侧内容共同包含在内，内部不再单独套圆角。桌面圆角 16px，手机圆角 12px，四边外沿均留 2px。统计与目录充分利用可用宽度，对话和长文使用适合阅读的宽度。 |
| ELO | 顶部常驻显示简洁数字，去掉胶囊外框，保留原有交互入口。主值表示用户总分，增量须标明实际统计范围。 |
| 手机 | 上下文目录转为抽屉，保留现有导航和沉浸页面规则。可用空间变化时优先调整排列，不依靠缩小正文和点击区域。 |

视觉层级统一为：导航通过底色区分，内容通过排版区分，浮层通过阴影区分。普通内容不反复套卡片，按钮按操作优先级使用外框与底色。

## 文字标准

以系统字体为主。桌面使用可用的系统界面字体，中文采用对应系统中文字体。文字层级按信息用途定义，避免所有内容统一为 13px。

| 用途 | 建议字号 | 建议字重与行高 |
| --- | --- | --- |
| 导航、目录、紧凑控件 | 13px | 常规 400，选中或重点 500，行高约 20px。 |
| 普通正文、表单 | 14px | 400，行高约 22px。 |
| 对话正文 | 桌面 14px，手机 15px | 400，行高 1.65；桌面约 23px，段落间距 12px。提问与回复同字号。 |
| 课程与持续阅读内容 | 16px | 400，中文和公式保持清晰。 |
| 分组标题 | 14px | 600，行高约 22px。 |
| 页面标题 | 20px | 600，行高约 28px。 |
| 统计主值 | 26px | 600，行高约 34px，数字使用等宽数字特性。 |
| 辅助日期、单位、说明 | 12px | 400，行高约 18px，不承载关键操作或主要正文。 |

字重主要使用 400、500、600。大小、位置和字重共同表达层级，不靠低对比度让信息退后。控件文字、图标和数值以实际视觉中心对齐。

依据用户提供的 Codex 窗口截图调整对话密度。截图经过缩放，参考字号与尺寸为视觉估算，UniMind 采用上述独立尺寸。对话表格与代码使用 13px；桌面输入文字 14px，手机输入文字 16px，避免聚焦输入时页面自动放大。导航行约 30～32px，手机常用点击目标保持 44px。

对话侧栏顶部仅保留新对话、搜索两个图标按钮。搜索按需打开弹层，支持标题和已加载的对话正文。项目按账号保存，支持弹窗创建、编辑名称与学习目标、折叠和在项目内新建对话。顶部与侧栏的新对话均继承当前所在项目；不在项目中时创建为未分类。会话创建时确定归属，未分类与各项目之间不提供迁移；删除会话只清除该会话，删除项目同时清除其中的全部会话与消息，操作前显示删除范围并允许取消。项目内每次对话读取最新的学习目标、背景与要求，作为用户提供的上下文；各会话的消息记录仍独立。进入小宇默认显示首页，历史对话从侧栏打开。用户气泡采用靛蓝强调色与对应的对比文字色。输入框统一为圆角表面，上方输入、下方工具与圆形发送按钮。

打卡统一位于学习门户，首次成功播放约 1.5 秒烟花，失败及重复打卡不触发。烟花使用独立画布，不拦截点击；减少动态效果时只显示成功提示。

## 间距与密度

以 4px 为基础间距单位。组内距离与组间距离分别定义，同类页面保持一致。

| 用途 | 建议尺寸 |
| --- | --- |
| 图标与文字、紧密相关信息 | 8px。 |
| 桌面控件内部 | 水平 12px，垂直根据控件高度居中。 |
| 列表行 | 桌面默认高度 36px；多行内容随文字增长。 |
| 相关信息组 | 间距 16px。 |
| 独立内容分区 | 间距 24px，需要分隔时使用一条细线。 |
| 主区边距 | 桌面通常 24px，窄屏通常 16px。 |
| 手机操作目标 | 常用独立点击目标至少 44px，避免密排造成误触。 |

紧凑布局主要用于导航、目录、工具栏和数据总览。对话与长文保留阅读行距。小宇首页留白承担开始对话的用途；统计、听课记录与打卡集中在学习门户。

## 颜色与表面

保留一个明确主色，暂定为低饱和靛蓝 `#4F5FA6`。主色统一用于主要按钮、当前选中提示、键盘焦点和关键数据图。石墨灰黑作为基础文字色，大面积导航与内容表面保持中性。品牌标志沿用现有资产，主色方案不再使用青绿色。

| 角色 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 主内容表面 | `#FFFFFF` | `#202227` |
| 导航表面 | `#F2F3F5` | `#141518` |
| 输入与辅助区域底色 | `#F6F7F9` | `#191B1F` |
| 上下文目录底色 | 导航表面占 55%、主内容表面占 45% 的混合色 | 同一混合比例 |
| 主要文字 | `#202226` | `#ECEEF2` |
| 次要文字 | `#60656C` | `#A5ABB4` |
| 分隔线与边框 | `#E2E5E9` | `#343840` |
| 悬停底色 | `#EEF0F3` | `#2A2E35` |
| 选中底色 | `#EFF1FA` | `#282E46` |
| 选中文字与图标 | `#4F5FA6` | `#A8B6F0` |
| 禁用底色 | `#E8EBEF` | `#303640` |
| 主要操作底色 | `#4F5FA6` | `#A8B6F0` |
| 主要操作文字 | `#FFFFFF` | `#171D35` |
| 主要操作悬停 | `#3F4D8D` | `#BCC7F5` |
| 键盘焦点 | `#4F5FA6` | `#A8B6F0` |

常规文字在实际背景上的对比度至少为 4.5∶1。必要的控件边界和焦点提示至少为 3∶1；极浅分隔线只承担辅助分组用途，控件不能仅靠该线才能被识别。

链接采用主色并提供下划线或明确的操作文案。悬停和键盘焦点可加强下划线，不把普通段落伪装成链接。常规标题、数值和正文保持石墨文字色，避免所有信息同时使用主色。

成功、警告、错误保留语义色，同时配文字或图标。浅色模式分别使用 `#166534`、`#92400E`、`#B91C1C`；深色模式分别使用 `#86EFAC`、`#FCD34D`、`#FCA5A5`。成功色只用于确认结果，不作为主要操作色或大面积背景。

学习活动图采用主色的连续色阶。浅色模式从少到多为 `#EEF0F3`、`#D9DEF0`、`#AEBCE0`、`#7C90C7`、`#4F5FA6`；深色模式为 `#303640`、`#394465`、`#526499`、`#7D90CF`、`#A8B6F0`。选中格另加清晰描边，并显示日期与实际次数。图表必须提供标签、图例和可读取的数值，不能只靠颜色传达含义。

默认表面为不透明的中性底色。内容页不增加大面积渐变或背景纹理。浮层以边界和轻阴影表达覆盖关系；半透明材质仅在背景干扰可控时使用，深浅模式都须保证文字可读。

## 圆角、边框与阴影

| 对象 | 标准 |
| --- | --- |
| 普通按钮、输入、列表选中背景 | 8px 圆角。 |
| 菜单与弹窗 | 12px 圆角。 |
| 主工作区 | 桌面 16px、手机 12px 圆角。功能 sidebar 外统一为一个面板，由面板外框裁切目录和内容的四个外角，使用现有边框色与轻阴影明确整体边界。顶部操作与滚动内容在面板内，不增加重复的内容内边距。目录、内容、主色与深浅模式沿用 UniMind 配色。 |
| 对话输入容器 | 16px 圆角。 |
| 圆形按钮 | 限于发送、头像等有明确用途的控件。 |
| 普通内容分区 | 对齐、间距与必要的细分隔线，不为每个统计值和分组套卡片。 |
| 普通控件 | 边框最多 1px，必要时采用浅底色区分。 |
| 浮层 | 一条 1px 边界，加一层轻阴影；浅色模式建议 `0 8px 24px rgb(20 25 30 / 10%)`，深色模式建议 `0 8px 24px rgb(0 0 0 / 28%)`。 |

控件圆角按角色固定。列表选中状态不同时堆叠边框、阴影、彩色图标和色条。多个触发区域相邻时保持明确边界，避免点击位置含糊。

## 图标与徽标

统一沿用现有 Phosphor 图标，不新增另一套图标库。桌面功能导航图标约 18px，控件内部图标约 16px，移动端导航按既有布局保持可读尺寸。默认使用同一笔画与常规样式，尺寸或字重变化须有角色依据。

图标颜色跟随文字。功能导航通过选中背景与文字对比表达当前位置。悬停、聚焦与触摸都应能获得图标名称；删除、发送等仅图标按钮必须有可访问名称。

徽标只用于需要用户注意的数量或状态，例如未读通知。ELO 为普通数字入口；成就数量放在成就相关区域或菜单中，保留原来的访问路径。会员、机构、权限等信息按任务需要显示，避免在每个页面重复陈列。

## 控件与状态

每个控件须完整定义默认、悬停、按下、焦点、选中、禁用、加载状态。状态变化不得改变控件尺寸或让相邻内容移动。

| 控件 | 默认行为与层级 |
| --- | --- |
| 主要按钮 | 靛蓝底色与浅色文字；同一操作组通常只保留一个主要操作。深色模式使用浅靛蓝底色与深色文字。 |
| 次要按钮 | 中性表面，必要时有细边框，正文色文字。 |
| 工具栏操作 | 透明底色，悬停出现浅底；图标和名称保持可辨认。 |
| 文本操作 | 主色并有明确文案或下划线，可见的键盘焦点。 |
| 输入框 | 浅灰底或白底，文字 14px；对话输入与手机可编辑文字至少 16px。 |
| 列表与目录 | 整行是明确点击目标。选中用浅底与 500 字重，悬停不冒充选中。 |
| 分段控件与标签页 | 只用于实际内容分类。选中样式、键盘操作、标签和内容必须同步。 |
| 弹窗与菜单 | 开启时焦点进入，关闭时回到触发器；支持 Escape，内容不超出可用屏幕。 |

键盘焦点采用约 2px 描边，与控件间隔约 2px。复合输入框只显示容器的一圈焦点，避免文本框与外层出现两圈重复描边。

禁用状态使用降低强调程度的中性色，移除悬停和按下反馈；图标与文字仍能被辨认，不仅依靠整体透明度处理。加载状态保留按钮宽度，使用旋转提示与状态文案，阻止重复提交。

## 动效

| 场景 | 规则 |
| --- | --- |
| 悬停与颜色反馈 | 约 120～150ms。 |
| 按下反馈 | 约 100ms，主要通过底色变化；少量独立按钮可缩放至 0.98。 |
| 菜单、弹窗和内容进入 | 约 180～220ms，移动距离最多 4～6px，保持焦点与布局稳定。 |
| 页面与滚动 | 小宇首页仅显示对话入口，删除第二屏与下滑提示。学习门户与其他内容页面使用常规滚动。 |
| 下滑提示 | 轻微位移，最多两次提示后停止，悬停或聚焦时停止。 |
| 加载 | 仅在实际等待期间持续，不为静态数字和图标添加循环动画。 |

减少动态效果开启时取消位移、缩放和非必要入场动效，导航滚动立即完成。动效不能成为唯一的状态提示，错误、成功与加载仍有文字或图标表达。

## 页面应用

小宇的新对话首屏包含标题与输入入口。未分类标题为「我们要做些什么？」，项目标题为「我们要在项目名中做些什么？」，项目名带虚线下划线，点击打开项目选择菜单，可搜索项目、查看当前选择或返回未分类。选择后进入相应的新对话入口，已有会话的归属保持不变。标题桌面 30px、手机 24px，长项目名可换行。输入容器桌面最大宽度约 680px，对话正文使用约 760～800px 的阅读宽度。统计区充分利用剩余主区宽度，相关数字对齐，四项主要指标排列一致；11 个快捷任务保持完整且可发现。

课程目录沿用学科、专辑、课程之间的层级。课程总览保持观看记录、继续学习、进度、资料与操作的关联。继续学习使用适合操作的尺寸，不因扩大封面和欢迎语挤走实际课程内容。

成绩、成就、训练和表单使用同一套文字、颜色、控件状态和表面规范，按各自内容组织页面。训练过程、视频播放和手机沉浸页面保留任务所需的布局与导航规则。

习题首页保留 Memorix-Field 的大字号主文案，突出产品名、持续进化的调度算法与强化记忆的用途，沿用 UniMind 主色。桌面介绍标题最大 40px，手机 24～32px；移除「第二代智能评估系统」副标题与小字号概述，完整原理通过「了解双引擎」展开。待复习、接近遗忘、尚未练习与主文案排列在一起。本轮训练使用完整的设置卡片，题数、难度和学科按网格对齐，底部排列练习偏好与开始按钮。曲线迁到学习门户，做题页集中于产品介绍与训练操作。

错题复盘顶部显示错题总数、累计错误次数与可练专项。错因专项和考点专项在同一容器中分栏排列，下方展示错因占比与考点分布；比例条只表达后端提供的错题占比。本轮题数按专项实际题目数量显示。桌面的正常练习与错题专项共用 AssessmentDialog，使用相同的题干、答案区、题目导航与底部操作；手机均使用 TestSessionPage 的全屏逐题流程。专项关闭或提交后返回错题复盘。选中答案、收藏和掌握状态使用主色，选项字母不加装饰徽标，主观输入在手机上保持 16px。

学习门户在「练习表现」之后显示「记忆保持趋势」，保留 Memorix-Field 品牌归属。近 90 天平均预测、实际回忆表现使用百分比，图表提供百分比刻度、日期、实线／虚线图例与说明，只统计有复习记录的日期，日期间距按实际时间计算。每天的数值、预测误差和最近算法更新收进详情；误差不标为准确度，算法改善率不解释为学习成绩提升。数据不足与请求失败分别提示，保留刷新与开始练习入口。

本次界面验证：本地示例数据检查了记忆趋势的数据不足提示、正常图表、百分比转换和详情中的每日数据、算法更新记录。桌面开始练习正常；320px 自定义题数、难度、学科与偏好可传到手机练习页，输入字号 16px，开始按钮 44px，页面无横向溢出。图表仅在自身区域横向滚动。TypeScript 构建检查、Vite 构建和 diff 空白检查通过，浏览器未记录错误。本次未修改后端算法，也未调用真实模型批改。

错题复盘调整验证：本地示例数据验证了专项题目顺序、主客观作答、收藏、掌握标记，以及桌面关闭和桌面／手机提交后的返回路径。桌面正常练习与专项窗口的尺寸、题干字号、行高和选项间距一致；320px 复盘和练习无横向溢出，主观输入为 16px。产品详情中的双引擎原理完整保留。类型检查、构建与 diff 空白检查通过，浏览器未记录错误。提交仅验证示例接口流程，未调用真实模型批改。

## 实施与验收

本轮已更新共享设计变量，整合应用框架，并将小宇、课程与相关顶栏浮层应用到实际页面。后续业务页面继续复用这些变量与控件标准。

1. 桌面 1280×720 与 1440×900、手机 390×844 与 320px 宽度下没有非必要的横向滚动、遮挡或文字裁切。布局或内容增加时合理换行与滚动。
