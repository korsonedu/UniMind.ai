# UniMind 前端设计规范 v1

基于正确仓库 `korsonedu/UniMind.ai`，基线 `186f307`。整个应用使用正式路由与页面逐项改造。

- 重点色：青绿 `#0F766E`。用于主要操作、链接、必要的选中提示和数据图；语义错误色保留。
- 方向：苹果原生应用的工具栏、分组列表、分段控件与中性表面。保持适合日常操作的密度。
- 左栏：桌面固定 64px，沿用现有功能图标。鼠标悬停、键盘聚焦显示名称；链接提供可访问名称和当前状态。移除展开按钮。
- 中栏：小宇与课程默认 208px，较窄桌面课程中栏 192px。工作台中栏 176px。目录标题保持单行，过长省略并提供完整名称提示。保留对话目录的宽度调整。
- 三栏只用于目录与内容有关联的工作区。报告、成就、表单、训练过程不强行新增中栏。
- 正文、树节点与控件以 13px 为主。层级主要通过位置、分组、分隔线和选中背景区分；课程学科不使用微小字号。
- 圆角以 8–12px 为主；细边框、轻阴影、中性底色。避免大面积渐变、大图标、无意义徽标与装饰。
- 页面仅保留必要名称、数字、状态和操作。说明与帮助按需展开，移除重复说明。
- 桌面目录在窄屏转为抽屉，手机保留现有导航与沉浸页面规则。

课程中栏采用学科 → 专辑 → 课程树，标签、学习状态、知识点与排序为独立筛选条件。组合标签保留交集筛选。主区提供欢迎、时间、学习频率、观看时长、完成情况、ELO 总数与近七天增量、继续观看、观看分类、课程资料与工具。活动可切换周柱图、月历、热力图。

课程详情保持连续页面，使用本仓库原播放器、字幕、AI 大纲、奖励、专辑课程和下载，不拆成三个内容 tab。观看活动记录实际播放经过的时间，跳转进度不算观看时间；重复事件和完成奖励幂等。历史进度继续保留，缺失的历史时长不推算。

小宇是独立 planner 功能。保留 11 个快捷任务、会话管理、打卡、诊断、学习统计、成就、考试、SSE 工具过程、可视化、公式与反馈。ELO 主值为用户总分；当前接口提供的增量为近期考试增量，明确标识其范围。

## 调试

完整应用：`http://127.0.0.1:5174/?preview=1`；课程：`/courses`；小宇：`/xiaoyu`。

开发模式加载本地示例数据，沿用实际 App、权限守卫、布局、路由和页面。调试条可切换学生、教师、平台身份，或连接真实后端。未模拟的业务操作会明确返回“需要连接真实后端”；真实支付、上传与 AI 服务需要实际后端。示例身份不写入真实登录存储。生产构建不加载示例模块。

真实后端需应用新增 `courses.0023_learning_portal` 迁移。迁移仅在隔离测试数据库验证，未操作生产服务。
