# 功能改造清单

按 `App.tsx` 注册路由和现有页面分析。先建立保留清单，再逐个功能调整；未列为已改造的页面目前保留原实现。

| 功能 | 布局判断 | 必须保留 | 状态 / 下一步 |
| --- | --- | --- | --- |
| 全局导航 | 固定图标栏 + 原有顶栏 | 角色与功能权限、账户菜单、ELO 排名、成就、通知、邀请、账单、退出 | 左栏固定 64px，名称提示支持悬停与聚焦 |
| 课程中心与课程详情 | 树目录 + 门户 / 连续课程页 | 搜索、组合标签、知识点、专辑、排序、管理入口、播放暂停、进度、倍速、静音、全屏、续播、字幕、大纲定位、奖励、资料下载、相关课程 | 已接入完整应用；补充实际观看活动、稍后观看接口 |
| 小宇 | 会话目录 + 学习概览 / 对话 | 11 个任务、历史搜索与切换、新建与删除、诊断、打卡、学习数据、成就、考试、工具流、可视化、反馈、公式与练习入口 | 已改造正式组件，保留原 runtime |
| 习题训练与错题复盘 | 总览与操作区；答题时单主区 | 训练偏好、知识点、数量、复习推荐、Memorix 曲线与优化历史、收藏、掌握、交卷、错因与考点专项 | 下一批：统一统计与分组控件，保留所有训练入口 |
| 成就 | 单主区 | 分类、进度、解锁状态与日期 | 统一列表密度，成就说明按需展开 |
| 成绩报告 | 单主区 | 成绩、ELO、统计、雷达、日活动、考试、成就、PDF | 保留图表与导出，统一指标区 |
| 知识地图 | 树目录 + 图谱 / 节点详情 | 搜索、图谱与列表切换、根节点、掌握状态、关联课程 / 文章 / 题目、训练 | 保留空间探索，统一树与详情面板 |
| 文章与阅读 | 筛选目录 + 列表；阅读时连续内容 | 标签、搜索、分页、列表 / 网格、正文、发布与管理 | 阅读页无需常驻三栏 |
| 答疑 | 分类 / 搜索 + 讨论 | 提问、附件、筛选、搜索、回答与权限操作 | 统一讨论列表与编辑区 |
| 自习室 | 专注工具 + 交流区 | 计划、任务计时、暂停 / 继续 / 结束、跨路由会话、广播、在线用户、聊天、图片、GIF、撤回 | 保留工具布局，不增加无意义目录栏 |
| 个人设置与账单 | 单主区分组表单 | 资料、头像、偏好、通知、会员与订单、导出、账户操作 | 统一表单语言，不改业务流程 |
| 教师工作台 | 会话 / 任务目录 + 工作区 | 出题 Agent、会话、上传、工具与任务、知识体系、邀请 | 原功能保留，中栏缩宽；后续复用原生工作区样式 |
| 题目、课程、文章、知识树、资源管理 | 按资源使用目录 + 表格 / 编辑器 | 搜索、过滤、分页、CRUD、导入导出、批量操作、排序、上传 / 续传 | 先统一工具栏、表格和编辑表单 |
| 机构看板与学员 | 看板单主区；学员表格 + 详情 | 机构统计、成员、班级、权限、邀请、考试与成绩、配置 | 保留所有层级和机构隔离 |
| 市场、API 平台、机构设置与审计 | 列表 / 分组表单 / 日志 | 市场业务、API 访问、机构商业配置、审计筛选与查看 | 按真实业务逐项调整 |
| 平台管理、激活码、模板、系统设置 | 管理表格与分组表单 | 平台权限、数据分析、人员与权限、激活码、提示词版本、系统配置 | 保留原路由与管理行为 |
| 登录、注册、验证、诊断、支付、法务与公共页面 | 独立流程 | 验证、协议、支付结果、诊断提交等完整流程 | 仅在相应功能改造时调整，不强加三栏 |

本地示例数据用于界面评审。完整应用入口支持实际页面导航，不以功能占位页替代原页面。各功能真正的服务端行为仍由对应后端和权限控制。
