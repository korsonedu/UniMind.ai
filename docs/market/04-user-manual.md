# UniMind 用户手册

按 2026-10-25 本地源码整理。本文描述当前学习端与后台分工，不代表本次清理已发布到生产。页面展示的服务状态、额度和商品参数优先。

## 登录与服务状态

从 `/login` 或 `/register` 登录注册。已登录后默认进入小宇，不需要选择教师身份、创建机构或输入激活码。旧邀请地址已移除，加入机构接口已经停用；课程身份由管理员直接调整。

非课程学员可以使用小宇普通问答、本人会话和账号服务。课程学员取得课程交付能力，仍受管理员配置的逐人功能开关约束。历史教师或机构所有者身份不自动取得后台权限。

## 小宇与笔记

在 `/xiaoyu` 提问，可使用历史会话、会话项目和当前开放的学习能力。非课程学员购买 AI 加量后仍维持原服务范围。

在 `/notes` 管理笔记、笔记本、标签及本人笔记内容。聊天可以参考选定笔记，长期关联与本次参考分别管理；Agent 回答留在聊天中，笔记内容由用户编辑。不要把历史侧边讨论面板的截图当成当前界面操作指南。

Agent 回复的赞踩继续保留。独立产品反馈按钮和满意度调查已在本地退出，练习批改与解析不受此项清理影响。

## 课程、训练与学习记录

| 入口 | 可以做什么 |
| --- | --- |
| `/courses` | 按学科、模块查看课程，继续观看，打开课件和资料 |
| `/tests` | 配置本轮练习、查看复习状态、进入考试或错题复盘 |
| `/report-card` | 查看本人学习与练习记录 |
| `/qa` | 阅读和参与课程答疑 |
| `/study` | 使用自习室、专注计时和学习交流 |

这些功能依赖课程学员状态和对应权限。入口可见不保证资源已授权；直接请求 API 与文件仍由服务端校验。独立知识地图页面已退出，知识点数据和 Memorix 调度继续使用。

## 我的服务与 AI 加量

在 `/billing` 查看当前学员状态、本周基础额度、剩余加量及真实线上订单。课程在线下收费，线下课程不会在这里生成虚构的已支付订单。

基础额度按上海时间周一 00:00 恢复，未用次数不累计。`users.0073` 的初始化默认值是非课程学员 20 次／周、课程学员 200 次／周，实际以后台配置为准。一次完整成功答复计一次，失败或取消不扣次；同次请求重试不重复扣次。

在 `/pricing` 查看已上架 AI 加量商品，登录后进入 `/checkout`。初始化商品为 9.9 元／100 次、90 天有效，后台人工配置可以改变展示值。支付能力取决于网关配置，商品可见不代表支付已经可用。购买加量不改变课程身份，加量不会每周重复发放。

## 教学与内容管理

两名授权操作者在 Directus 的 `/admin/unimind-admin` 管理教学、题库、知识目录、内容任务、课程、学员、AI 加量商品、订单、AI 配置、通知和操作记录。学习端的 `/workbench`、`/management`、`/institution` 等旧地址不再提供管理界面。

生成结果先进入待审核区，确认后入库；通知先展示接收人和正文，再确认发送。学员分类与功能开关不依赖旧机构套餐。接入和操作细节见 [管理扩展说明](../../admin-extension/README.md)。

## 常见边界

- 课程身份或功能权限需要调整时，在“我的服务”使用“联系我们”，或联系科晟管理员。
- 额度用完后可以等待下周恢复，或查看当前上架的 AI 加量。
- 旧机构套餐、自动试用、激活码、API 销售、模拟面试和专属学生导师不属于当前开放功能。
- 本地 `?preview=1` 使用虚构示例数据，不能作为真实订单、真实学习效果或生产发布证明。预览中缺少某接口数据时，应先区分模拟缺口与真实后端故障。
