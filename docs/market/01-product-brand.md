## 一、定位与品牌

### 1.1 一句话定位

**中文**：UniMind 是 Agent 驱动的新一代智能教育基础设施——从教师出题、学生刷题、评分批改到知识追踪，全链路 Agent 化。嵌入，不替代。

**英文**：UniMind is Agent-driven next-generation education infrastructure — full-chain Agent automation from question generation and grading to knowledge tracking. Embed, don't replace.

**Slogan**：将技术转化为教育生产力。

### 1.2 电梯演讲（30 秒）

我们不是"给教育产品加了 AI"，而是**用 Agent 重构了教育的底层基础设施**。

UniMind 部署了两个自治 AI Agent：**小宇**是学生唯一的 AI 入口——诊断薄弱点、规划学习路径、讲解知识难点，不等你问就主动分析；**工作台**是教师的教研引擎——一句话出题，背后四个 Agent 对抗博弈，自然语言操作全流程。

底层是 Memorix 自进化记忆调度引擎——融合 Weibull 遗忘模型 + 知识图谱拓扑分析，在线随机梯度下降实时进化每个学生的记忆模型。

我们有一条硬线：**AI 在执行域，教师在判断域。** 嵌入，不替代。

### 1.3 品牌故事

传统教育科技产品将纸面题目迁移到了屏幕上，但学生的学习状态并没有因此变得更可见。它仍被简化为已做题目的列表，系统不理解每条记忆痕迹有自己的衰减速率，需要在不同时间点被重新激活。一个无法建模这种状态的系统，本质上是一个题库。

教师端存在对称的低效。现有工具让教师看到成绩和完成率，看数据之后的一切判断仍需教师自己完成。哪一个知识点需要重点讲解，哪一个学生正在掉队，什么时候该布置什么作业——这些问题没有工具参与回答。工具承担了记录，却把判断的负担连同效率的损失一起留给了人。

这一判断决定了 UniMind 的架构选择。AI 提供了根本的解决路径——传统系统做不到的「理解学生状态并做出判断」，在语言模型的能力范围内变得可行。但 AI 本身不构成产品壁垒：任何团队都可以调用 API。UniMind 的差异在于 **ARCA 架构**，四层逐层为 AI 提供教育领域必需的感知与约束。AI 是交互层，ARCA 是支撑层——前者负责理解与生成，后者约束 AI 在正确的教育边界内行事，同时赋予 AI 对教学过程的感知能力，使其不只是一个对话接口。

传统教育 SaaS 是"功能拼盘"——刷题一个模块、课程一个模块、AI 助手一个聊天框。UniMind 从第一天就在构建**基础设施层**：

- **Agent 统一运行时**：所有 AI 能力共享一套 Bot → ToolExecutor → ChatService 架构。新增一个 Agent，只需定义工具集和系统提示词——不需要重建流水线。
- **Memorix 自进化记忆引擎**：融合 Weibull 遗忘模型与知识图谱拓扑分析。每道题的答题行为实时更新个人记忆参数，记忆衰减状态 + 知识结构依赖统一决定"下一步该学什么"。
- **对抗式内容生产**：出题不是"AI 生成 → 人工审核"的单次调用，而是 4 个 Agent 迭代博弈，三维质量评分，不达标不放行。
- **MUTAR 自进化闭环**：每次 Agent 对话自动采集轨迹，用户反馈闭环评估，系统自主优化 Prompt 策略。用得越久，Agent 越聪明。
- **嵌入架构，不是替代**：教师设定难度、选题决策、布置时机——这些是判断域，AI 不越界。AI 做搜索、生成、校验、汇总——这些是执行域。两层之间是硬约束。

这就是"新一代智能教育基础设施"的含义：不是给教育加 AI，而是用 AI 重构教育。

## 二、产品哲学：嵌入，不替代

> 详见 `docs/design/product-principles.md`

教育 AI 产品面对的核心问题：人和工具的关系怎么摆。

有一条路是**替代**。用 AI 出题替代教师出题，用 AI 批改替代教师批改。逻辑很直——AI 做得更快，为什么不替。

另一条路是**嵌入**。AI 做搜索、生成、校验、汇总——这些不需要判断的事。教师做判断——用什么难度、选哪些题、什么时候布置、怎么调整教学。

我们选第二条。这来自一个更基本的判断：**教师对学生的责任不该被代理。** 工具可以更快更准更不知疲倦，但教什么、怎么教，始终是教师在决定。

### 判断域 vs 执行域

| 域 | 角色 | 职责 |
|----|------|------|
| 判断域 | 教师 | 难度设定、选题决策、布置时机、教学调整 |
| 执行域 | AI | 搜索知识点、生成题目、校验质量、汇总数据 |

两层之间的接口是**硬的**：

- 难度由教师指定，模型在这个约束下生成
- 所有有实际后果的操作——布置作业、发送通知、题目入库——入口只有一个：教师点击确认
- 代码层不存在一条绕过教师确认的路径

这不是"人类在回路中"的产品理念。在架构层面，它是硬约束，不是可选项。我们没有全自动模式，没有跳过教师确认的开关。在教育场景里，**执行效率的提升不应该以让渡判断权为代价。**

### 系统演化方向：外循环

- **替代式（不做）**：模型产出 → 模型评估 → 模型优化。时间越长，系统越趋近模型自己定义的标准。
- **嵌入式（在做）**：模型产出 → 教师评估 → 模型从教师反馈中调整。时间越长，系统越贴近使用者的判断。不同机构用同一个系统，半年后系统的行为会不一样。

## 三、ARCA 四层架构

ARCA 是系统的骨骼。四层自下而上，定义系统长什么样。

| 层 | 名称 | 职责 |
|----|------|------|
| L1 | 基础框架 | 对话生命周期管理、Bot 注册调度、工具权限控制、意图预筛选路由、模型分级调度及通信传输 |
| L2 | 记忆系统 | 统一调度中枢——每位学生每个知识点的掌握概率、遗忘速率、最佳复习窗口。出题、练习、批改、课程推荐作为执行节点接入 |
| L3 | 教育闭环 | 教、练、测、评四环节首尾相连——知识树按认知结构组织资源，Memorix 驱动练习调度，IRT 自适应诊断，错因分类联动变式题匹配 |
| L4 | 测评引擎 | IRT 三参数 Logistic 模型 + MML-EM 参数估计，机构级参数隔离，Fallback CTT 保证新题冷启动 |

**关键设计决策**：Memorix 是系统的时钟，不是功能模块。所有教育行为——出题、练习、复习、考试——都由记忆状态驱动。上层不直接操作数据库，通过 MemorySystem 接口层隔离。这保证了"Memorix 驱动一切"在代码层面被强制执行，不依赖开发者的自律。

Agent 是交互层，ARCA 是支撑层。新增 Agent 只需：① 写 prompt 文件 ② 在 BotRegistry 注册 ③ 可选写 ToolExecutor 子类。四层能力自动继承。

## 四、双 Agent 能力

两个自治 Agent 分别对应教学关系的两端。Agent 的核心价值不在"能对话"，而在每次响应之前已经完成了信息聚合与判断。

### 4.1 小宇 — 学生学习教练

**一句话**：你唯一的 AI 入口。不等你问，主动分析、规划、讲解。

小宇是学生端 AI 入口，拥有 30+ 工具，承担学习教练职能：

- 诊断能力起点，追踪每个知识点的记忆衰减
- 在遗忘临界点触发复习，对错题进行错因归类并匹配变式题
- 根据长期目标制定和调整学习计划
- 综合记忆状态模型、到期复习列表、错题分布和知识掌握热力图给出具体建议

**自进化能力**：
- LLM 驱动的自适应指令：自动识别学习风格（公式导向/视觉型/例子驱动/记忆技巧型）、认知状态（专注/焦虑/过载/积极），动态调整教学策略
- 跨会话记忆：持续积累对学生的理解——学习风格、长期目标、偏好——每次对话都在变得更精准

**典型对话**：
- "你这周微积分正确率下降了，建议先复习洛必达法则的 3 个考点"
- "你离考研还有 87 天，根据薄弱点分布，这是本周的优先级清单"
- "不定积分·分部积分法即将遗忘，建议今晚复习 5 题，预计用时 8 分钟"

### 4.2 工作台 — 教师教研引擎

**一句话**：自然语言驱动全流程。出题、查数据、管作业，一句话完成。

工作台是教师端 AI 入口，拥有 20+ 工具，教师通过自然语言完成教学操作：

- 按知识点和难度出题并发布
- 启动 ARC 四 Agent 管线精修题目
- 查看题库统计、布置和批改作业
- 查询个体学生和班级层级的学情数据

**嵌入架构**：
- 难度由教师指定，模型在约束下生成
- 所有有实际后果的操作——布置作业、发送通知、题目入库——入口只有一个：教师点击确认
- 不存在绕过教师确认的路径。这不是可选项，是硬约束。

## 五、核心差异化能力

### 5.1 Memorix 记忆调度引擎

**定位**：不是间隔重复，是记忆进化 × 知识图谱。

传统间隔重复算法将每个知识点视为独立记忆单元。但知识是一张连通图——练习分部积分时，不定积分的计算技巧在过程中被真实调用，产生可测量的跨知识点迁移。FSRS 不具备捕捉这种迁移的机制。

Memorix 的核心创新是**图扩散状态估计器**：系统为每个学生维护知识点激活向量，当某知识点完成成功复习后，激活变化沿知识图谱的拉普拉斯算子传播到相邻节点。复习预算从"已通过迁移间接强化"的知识点撤出，重新分配给真正需要加强的节点。

| 维度 | FSRS v4.5 | Memorix |
|------|-----------|---------|
| 遗忘模型 | 幂律近似 | Weibull 分布（多一个自适应形状参数 k） |
| 更新方式 | 批处理 L-BFGS-B（每日一次） | 在线梯度下降 + Nesterov 动量（每题更新） |
| 损失函数 | RMSE | Brier Score（严格 proper scoring rule） |
| 个性化 | 全局权重 | 用户权重 + L2 正则向全局先验 |
| 知识嵌入 | 无 | 知识点向量嵌入影响 stability |
| 调度决策 | 目标 retrievability | 遗憾最小化：平衡遗忘风险与复习成本 |

**实测数据**：300 名学生、150 天、215 知识点 CFA 知识图谱仿真中，Memorix 相较 FSRS 实现 5.8% 的留存率提升。消融实验确认全部优势来自扩散机制，关闭扩散追踪器后性能跌至 FSRS 以下 2.4%。预测 RMSE 比 FSRS v4.5 降低 13.7%。

### 5.2 4-Agent ARC 对抗出题管线

**定位**：四个 AI 博弈，一套高质量考题。

单次 LLM 出题通过率约 60%。ARC 对抗管线通过率 85%+。差距不在模型能力，在**架构**。

```
Author（生成候选）→ Reviewer（深度思考，三维评分）
  → [不达标] AuthorRevise（逐条修改）→ Reviewer（再评）
    → [达标或3轮上限] Classifier（最终审计）
```

- Reviewer 用 Pro 模型开启思考模式（唯一显式开 thinking 的任务）
- 三维度评估：区分度、表述清晰度、知识覆盖度
- 最多 3 轮迭代，超限取最高分版本
- Classifier 做最终审计：答案正确性、认知层级、难度合规、知识标签

### 5.3 MUTAR 自进化闭环

**定位**：系统的进化引擎。运行在 ARCA 之上，系统如何变得更好。

MUTAR（Measure → Umpire → Think → Adapt → Refine）是系统的持续优化闭环：

- **轨迹自动采集**：每次 Agent 对话自动记录完整轨迹——工具调用链、轮次数、成功率
- **用户反馈闭环**：赞/踩反馈自动关联到对应轨迹，覆盖自动评估结果
- **优化建议生成**：周期性聚合分析，识别高频失败模式，生成 Prompt 优化方案

一个机构用了半年的 UniMind，和刚注册时已经不是同一个系统。Agent 的回应风格、出题偏好、知识树结构都向这个机构的实际教学场景收敛。这正是通用 chatbot 做不到的事。

### 5.4 四层个性化

从冷启动到深度了解，四层递进的个性化：

| 层级 | 机制 | 作用 |
|------|------|------|
| L1 诊断测试 | 首次登录 IRT 自适应选题快速评估 | 冷启动：初始化知识掌握水平 |
| L2 Memorix | 每次答题实时更新记忆参数 + 图谱掌握度 | 行为建模：精准预测遗忘临界点 |
| L3 Agent Memory | 对话中自动提取偏好和习惯 | 深度个性化：越用越懂你 |
| L4 自适应指令 | LLM 分析记忆生成教学策略 | 动态调整：根据认知状态和学习风格优化教学 |

### 5.5 知识图谱

体系化知识管理是区别于碎片化刷题工具的根本特征。系统内置 13 个学科全景知识图谱（金融 431、CFA、CPA、法考、法学、教资、教育学 311、计算机 408、高中数学、高中物理、高中化学、高中生物、USMLE），四级树状结构从学科展开到篇章、小节、考点，总计 4,486 个知识点。机构可导入自定义知识树（Markdown 格式），AI 也可根据学科名称自动生成。

## 六、使用场景

### 学生端

新用户首次登录后，系统推送一组诊断测试题。10 道题覆盖该学科的主要知识板块，每题难度根据前序答题表现动态调整。提交后输出初始能力估计和各知识点掌握概率，Memorix 以此为起点开始追踪记忆衰减曲线。

日常使用中，学生打开小宇对话。小宇已拉取到期复习列表，按紧迫度排序："你今天有 3 个知识点进入遗忘窗口了，不定积分的分部积分法上次正确率 60%，我选了 5 道题，从基础题开始，准备好了吗？"做错的题目自动归入错因分类——概念错误匹配讲解型变式题，计算失误匹配练习型变式题——插入后续复习队列。

当知识点即将进入遗忘窗口，系统通过 PWA 推送提醒。学生打开小宇，题目已经在对话里等着。

### 教师端

教师打开工作台，用自然语言描述出题需求："帮我出 5 道高中数学导数应用的大题，难度中等偏上，要考察分类讨论思想。"工作台搜索知识树中对应的知识点节点，生成题目并逐道展示。教师逐题审核——偏简单就换掉，题干表述不清晰就送 ARC 管线精修。确认质量的题目一键入库，再一句话布置给指定班级。

第二天，教师查看作业提交情况。客观题已自动批改完成，主观题由 AI 批改后标注了评分依据，等待教师复核。一键通过后成绩发布，每位学生的记忆模型参数随之更新。教师在对话中追问薄弱项，工作台返回按班级和知识点交叉统计的排序，附带建议。从出题、发布、批改到薄弱点分析，整个流程在同一个对话界面内完成。

### 机构启动

新机构从注册到学生开始使用，全程不超过一个工作日。选择学科模板，导入或自动生成知识树，创建班级，生成邀请链接发给教师和学生。机构可为不同班级设定独立的难度基准和教学计划。14 天全功能试用期间可评估全部功能。

## 八、数据安全与部署

多机构架构决定了数据安全的起点：每家机构的数据在存储层物理隔离。机构的数据属于机构——系统不将其用于跨机构训练或模型优化，机构拥有全量数据的导出权。

认证体系以 httpOnly cookie 为核心，配合 CSRF 保护。浏览器端脚本无法读取令牌。四层 RBAC 权限体系（超管 → 机构所有者 → 教师 → 学生）叠加按定价方案的功能权限矩阵，每个 API 请求经过角色和方案的交叉校验。支付密钥等敏感字段以 Fernet AES 加密存储，加密密钥通过环境变量独立注入。

AI 调用层面，按任务类型的独立熔断器确保单个模型故障不会扩散至系统其他部分。所有 Agent 工具调用经过白名单审计——Agent 只能使用其 Bot 类型声明范围内的工具，越权调用在框架层被拦截。

部署支持两种方式。SaaS 云服务注册即用，30 秒完成初始化，机构无需运维。Enterprise 方案支持完整私有化部署至机构自有服务器，所有数据不出内网。

## 九、竞品对比

| 维度 | 传统 EdTech SaaS | UniMind |
|------|-----------------|------------|
| AI 角色 | 聊天框（被动问答） | 双自治 Agent（主动决策 + 工具调用 + 意图路由） |
| 出题方式 | 单次 LLM 生成 | 4-Agent 对抗博弈，最多 3 轮迭代 |
| 记忆算法 | SM-2 / 静态 FSRS | Memorix 自进化引擎（遗忘建模 + 知识图谱拓扑分析） |
| 个性化 | 用户画像 + 推荐 | 四层递进（诊断 + Memorix + 对话记忆 + 自适应指令） |
| 教学策略 | 固定模板 | LLM 驱动动态调整（学习风格 + 认知状态感知） |
| 教师角色 | 被替代（AI 全自动） | 被嵌入（AI 执行域，教师判断域，硬约束） |
| 扩展性 | 每个功能独立开发 | Agent 运行时，新增 Agent 只需定义工具 |
| 自进化 | 无 / 人工调参 | MUTAR 闭环：轨迹采集 → 反馈评估 → 自动优化 |
| 部署方式 | SaaS only | SaaS + 企业版源码交付本地部署 |

### 市场位置

当前教育 SaaS 的 B 端 AI 教学场景是小蓝海：
- **C 端 AI 教育**：学而思、作业帮、猿辅导、科大讯飞，全部面向家长和学生
- **B 端传统 SaaS**：校宝在线（25 万+ 校区），主打招生和教务管理，AI 出题/AI 教学未被占领
- **B 端 AI 教学**：UniMind 是唯一以 Agent-Native 架构做 B 端教学闭环的产品
