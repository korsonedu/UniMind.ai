# ULR 正式作答复盘验证

2026 年 11 月 23 日。对照使用主分支基线 `23eb7168`、实际 DSH SDK `0.2.1rc2` 和回环合成模型。两边走同一个小宇 SSE 入口，复盘同一份已正式提交的原作答。

| 场景 | 验证结果 |
| --- | --- |
| 已完成客观题评阅 | 两边都拿到原作答 B 和标准答案判分来源，各调用模型 1 次。ULR 从核验过的结果生成零分卡片，链接回到原任务。 |
| 评阅进行中 | ULR 直接返回已提交及处理状态，模型请求为 0。问答额度仍沿用现有结算规则。 |
| 主观评分 | 原作答、分数和模型评分来源通过核验。评分标准变更后，该旧结果停止用于复盘。 |
| 断线恢复 | 复跑发现 SQLite 状态查询与账本写入会争用。修复后两边共用短时额度锁，查询可等账本事务完成。 |

复盘正文在服务端再次核对原任务、评阅和权限后整体返回。现阶段复盘没有逐字预览，使用回环模型测得的耗时不用于判断生产首字延迟。主观评分的教学质量仍待真实数据评估。

8 项定向冒烟及 1 项实际 DSH SDK 对照通过。相关入口在 `backend/ai_assistant/tests/test_ulr_runtime_smoke.py`、`test_ulr_dsh_comparison.py` 及现有学习任务、恢复冒烟。
