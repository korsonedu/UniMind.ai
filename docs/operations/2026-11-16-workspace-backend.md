# 标准客户端机构 workspace 后端

机构服务通过显式 WorkspaceMembership 授权。用户自行注册，再输入邀请码；加入不修改历史 institution、owner/teacher 身份，不复制个人笔记、对话或观看记录。普通学习邀请码只创建学生成员与课程授权。

## 首次开通

在已完成迁移的部署环境中，指定现有账号作为首位管理员：

```bash
python manage.py provision_workspace --name '机构名称' --admin '已有用户名' --ends-on 2027-06-30 --max-students 50
```

名称、管理员、期限和名额须来自实际合作配置。命令不会接管历史机构，不自动生成演示机构，也不自动赋予平台后台权限。管理员登录标准客户端后，通过“设置 → 机构与学习服务 → 管理机构”管理课程和邀请码。

## 已接通

- `/api/users/workspace/`：当前成员身份、服务、授权课程；只有管理员能看到同机构学生、邀请码及真实用量。
- `invite-preview/`、`join/`：登录后校验与确认加入。邀请码、账号与机构名额在事务内加锁；重复领取不重复计数，不延长原权益。同一账号可加入多家机构，通过 `switch/` 选择当前机构，课程和管理操作按当前机构授权。
- `switch/`、`leave/`：已加入机构之间切换、退出。退出移除该机构的成员和课程授权，保留账号、笔记与聊天记录；重新加入需要有效邀请码并再次领取授权。退出当前机构后选中其余已加入机构中的第一家，无其他机构时恢复未加入状态。最后一位管理员需先移交管理身份。
- `courses/`：批量 MP4 上传，每批总计最多 200 MB，先保存草稿，提交后投递 Celery 任务。
- `courses/<id>/`：查看讲稿与知识结构、发布/下架、处理失败后重试。发布要求有效 ASR 文本、时间分段及与当前讲稿版本一致的知识结构。
- `invites/`、`invites/<id>/`：创建课程服务邀请码及启停。领取截止和学生服务期限分开；停用邀请码不撤销已领取的服务。
- `members/<id>/`：暂停或恢复学生的机构学习权限，保留账号和学习记录。

课程列表、播放器、讲稿、大纲、附件与小宇课程上下文使用相同授权范围。旧的课程学员身份不能扩大 workspace 学生的课程权限；未加入 workspace 的既有平台用户沿用原规则。

新增 workspace 只开放课程伴学及个人学习记录相关能力，题库等未接入的服务不自动随机构邀请码开放。历史 owner/teacher 不获得新管理权限。

## 内容处理与用量

需要重启加载新任务模块的 Celery worker。任务复用现有 ASR，由带讲稿分段编号的资料生成课程知识结构，保存来源分段和讲稿版本。知识结构失败后重试会复用已完成的 ASR。管理员读取状态时，超时任务显示失败并可重试，无需启用历史 Celery beat 调度。

课程详情按需读取，处理中的课程每五秒刷新状态。学生名额显示实际配置；处理分钟数、存储及成功学习问答显示真实累计值，不虚构未配置的额度。机构用量只计入发生时归属本 workspace 的成功 AI 请求。

机构课程暂不提供离线下载；媒体入口撤权后停止签发新地址，已签发 OSS 地址最多继续有效五分钟。普通个人业务的离线规则保持原状。

## 验证范围

本地定向冒烟使用隔离数据库和合成文件，外部 ASR/模型响应替身用于验证任务编排、来源校验及发布流程。它不证明真实视频转写或知识结构的内容质量。首次真实机构接入时，需要用其实际视频复核 ASR 与结构结果。
