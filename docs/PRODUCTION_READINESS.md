## 发行命令与边界

- `frontend/electron/npm run release:check` 只检查正式发行配置，不输出密钥，不安装或发布。当前因更新配置、Developer ID和公证配置缺失按预期失败。
- `npm run release:dist` 先预检、构建，再以forceCodeSigning打包。
- `npm run release:verify -- <产物路径>` 必须在目标系统执行：macOS核对正式bundleId、版本、精确发行者、codesign完整性、Gatekeeper与已装订公证；Windows核对Authenticode有效状态、精确发行者和版本。配置缺失、系统检查失败或空输出均拒绝。发行者白名单只接受非空字符串数组，Mac可填完整Developer ID证书名称或精确公司名称。
- 正式发行前须固定经确认的源码版本／快照，并保存对应产物校验值；当前混合工作区及未签名候选不作为发布版本。
- 现有`dist`、`dist:win`及Windows CI产物仍按未签名候选使用；预览不接收正式更新，不能把这些候选冒充正式包。
