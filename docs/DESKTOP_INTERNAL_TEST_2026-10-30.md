## 测试环境连接

两端默认访问`http://127.0.0.1:5175/api/ai/dsh-preview/student-b/`，使用隔离数据库中的合成学生。需要持续运行本地Vite和隔离后端。仅安装EXE或解压App不会带上这些服务。

本次Mac已有预览服务；Windows配合验收前，需要让Windows本机5175连接到同一隔离预览。若已有授权且可用的SSH访问，可由用户在Windows终端建立仅监听本机的转发：

```powershell
ssh -N -L 127.0.0.1:5175:127.0.0.1:5175 <已有SSH用户>@<Mac地址>
```

这要求Mac原本已提供授权SSH访问；本轮没有开启远程登录、开放防火墙或把开发服务暴露到局域网。若没有现成访问条件，应先安排测试环境连接，再进行Windows业务验收。无需复制真实账号、密钥或生产数据库。

## Windows实机验收

使用`frontend/electron/release-windows-preview/`中的x64 NSIS安装包。先核对目录内SHA256SUMS，记录Windows版本、安装路径与结果。测试窗口之间保留原数据，不主动退出账号，直到检查完恢复行为。

| 检查 | 通过标准 |
| --- | --- |
| 安装与二次启动 | 可选择安装位置，成功启动；连续打开仅保留一个主窗口；中文或含空格的用户目录可正常保存 |
| 桌面设置与托盘 | 默认通知和驻留关闭；开启驻留后关窗保留托盘，可唤回，菜单退出能结束应用 |
| 会话恢复 | 两个会话的未发送草稿独立；重新连接或终止Renderer后恢复原草稿；原任务只查询，不自动重复提交 |
| 下载恢复 | 下载可暂停与继续，退出重启后仍保留分片；完成后可打开独立离线库 |
| 离线学习 | 已下载视频断网可播放，暂停后重开恢复位置；复网显示已同步，重复同步不重复加时或奖励 |
| 账号与退出 | 自然登录失效提示重新登录，同账号恢复队列；主动退出提示待同步损失，清除缓存后不能继续播放旧账号课程 |
| 休眠与唤醒 | 恢复后能继续使用、恢复草稿并查询原任务；休眠间隔不计观看时长 |
| 卸载 | 正常退出后可卸载，应用快捷方式移除；重新安装后的缓存行为如实记录，不能把Windows默认保留userData描述为已清空 |

预览包不会注册正式`unimind://`协议，也不会接收正式更新。正式协议注册、通知投递及更新安装，应在对应发行候选与目标系统中另行验收；不能用Preview替代。
