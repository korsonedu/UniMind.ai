## 独立运行器

专用用户为 `unimind-learning`，家目录 `/var/lib/unimind-learning`。`/opt/unimind-learning-worker` 中保存两个独立脚本、固定 `playwright==1.59.0` 的 `venv` 和 Chromium Headless Shell 1217；代码、解释器和浏览器由 root 管理，运行用户不能改写。

生产通过临时 systemd 单元执行，最多同时 2 个，每个内存 512 MiB、禁用交换、最多 96 个进程、1 核 CPU 配额、10 秒服务时限与 12 秒父进程时限。单元使用非 root 身份、独立网络和临时目录、只读系统、隐藏用户目录、禁止获得新权限，并隔离 `/opt/unimind`、`/opt/unimind-venvs`、`/var/lib/unimind`。浏览器沙箱保持开启；生成代码只接收明确 JSON 输入，不获得 Django 或模型凭据。

Ubuntu 的用户命名空间限制需要固定 Chromium 的专用规则 `deploy/unimind-learning-chromium.apparmor`。该规则使用 `unconfined` 加 `userns`，安装须有明确授权；它不改变全局 AppArmor 限制，文件、网络和资源边界由上述 systemd 单元施加。浏览器升级后需重新核对规则中的可执行文件路径。

## 交互讲题与失败恢复修复

桌面端实际出现工具执行失败后长期停在“执行结果尚未确认”。账本已是 `released`，额度未扣除，但恢复接口对明确失败也返回 `unknown`；前端收到失败终态仍保留 pending 请求，后续刷新无法解除。

修复后，DSH 的明确失败将错误说明保存在既有预留响应中，恢复接口返回 `failed`；真正无法确定的旧记录仍保留 `unknown`。前端消费失败终态或恢复到失败时，会解除等待、保留草稿并显示错误，不自动重发或再计费，步骤汇总也明确显示本轮未完成。

“讲题＋交互”现在直接选择组合工具组，同时提供取题、题目详情与实验生成，不必在题库分组和编写分组间往返。每轮仍最多 8 个可见工具、6 次模型请求，权限和沙箱限制不变。此修复通过失败状态、原成功路径和组合工具可见性的定向冒烟，以及前端生产构建；不以重新执行用户原提问作为自动验收。

## 交互讲解卡片约束

交互卡片仅用于讲解和参数演示，不承载作答、预测提交或评分。DSH 讲解取题传 `purpose=explanation`，只读取题目作为材料；正常练习默认行为保留。长题干、推导和解释放在聊天正文，卡片只保留必要标签、单位、短提示、图形和控件，外层不再重复展示观察说明。

浏览器预检使用桌面 700×360、窄屏 360×420 的正文空间，检查页面溢出和通过 hidden/clip 隐藏的超出内容；失败返回具体元素及可用/实际尺寸。前端根据实际正文高度显示，最多420px，去掉原高度消息中重复添加的48px空白。

本轮隔离合成债券题完整 DSH 流程用了4次官方请求，包含取题、首次失败、自行修正、挂载与最终回答。独立检查进一步发现窄屏截断，额外2次修复请求中一次返回HTTP400，一次生成修正版；合计6次，未追加。最终模型修正版通过7组独立价格、参数恢复、桌面及窄屏尺寸检查，实际React组件的滑块、内存模拟保存和讲解按钮亦通过。最终修正版没有另做一次从空白对话开始的完整DSH模型验收，不能以此宣称普遍正确率。

失败的交互源码和浏览器诊断保存在当次预留响应的 `learning_failure` 中，失败释放额度时保留，供后续复现；步骤名称明确区分交互生成与资料查询。

## 解答场景限定与卡片设计

交互生成入口只向解答、概念讲解、推导及错因讲解提供。出题练习、批改计分、学习统计/报告、计划、自习、资源推荐及闲聊不提供生成工具；执行时再按服务器保存的当前提问复核，不能依靠客户端传入的“讲解”文字绕过。判定使用保守文本规则，短追问沿用同一对话、同一Bot最近的实际提问；模糊场景仍可用文字解答，不能据此宣称通用语义识别已验证。历史讲解卡片保留，正常练习及数据卡片流程保留。

讲解画布提供暖白、深墨、低饱和强调色的共享CSS变量、原生控件与键盘焦点样式，以及可组合的参数区、图形区、结果和短提示样式。模型仍自由编写HTML/CSS/JavaScript，布局按问题决定；提示词明确结果层级、间距、字体、单位及图形配色。外层统一标题、保存状态和继续讲解按钮，避免重复边框与无意义说明。

本轮未新增模型请求。入口限制及直接执行拒绝经过定向冒烟；实际组件的设计预览沿用上轮DeepSeek合成债券的计算逻辑，本轮调整排版和配色，不能称为新一轮自主生成结果。预览的宽窄屏尺寸、7组独立数值和控件保存通过本地检查。

## SVG文字碰撞预检

生成代码通过数值检查不代表图形可读。浏览器预检现会比对同一SVG内可见text元素的实际边界，在桌面和窄屏检查显著碰撞，返回重叠的文字与交叠尺寸；失败沿原有preview诊断反馈给模型，禁止挂载。不能靠修改数值断言使视觉错误通过。该检查不覆盖canvas内部文字，也不等于所有视觉问题已验证。

本轮使用上轮模型留下的“息票／面值”重叠源码复现，桌面与窄屏均被拒绝，诊断包含具体文字和交叠尺寸；分开图例的修正版通过，并检查5年期限。未新增模型请求。针对错误反馈回传及修复后挂载的模拟冒烟通过，未重新验收真实模型收到碰撞后能否自主修好。

已有本对话讲解卡片时，“柱子下面的字混到一起”“标签重叠”等明确修复反馈可继续读取并更新该卡片；出题、统计和计划限制仍优先。历史卡片不会批量自动重写。

生产复核发现原运行器没有中文字体，两个8px汉字被测得约9.8px总宽，导致同一源码在Mac碰撞、Linux却未碰撞。已安装配置的Ubuntu仓库字体包 `fonts-noto-cjk`；Linux预检先用fontconfig确认中文字体可用，缺失时明确拒绝挂载，不能把环境无法验证当作检查通过。不同系统的字体与渲染仍可能有差异，该修复不等同于跨端像素一致。

截至e10289e生产版本，更通用的截图视觉审查、交互状态截图以及常规图表的平台排版组件尚未实现；后续本地建设见下节，不与该次生产防护混为一谈。

## 独立截图审查与平台图表组件（2026-11-11 已上线启用）

浏览器运行器支持最多8张PNG：初始桌面/窄屏、每个成功控件检查后的桌面、最终窄屏。固定CSS像素比例，关闭截图时的动画，单张最多512KiB、合计最多2MiB；图片只作为运行器临时输出，回到后端后从预检报告移除，不写进聊天历史或持久卡片。持久证据为文档摘要、frame_id、像素尺寸、阶段和SHA256。

`UNIMIND_LEARNING_VISUAL_REVIEW_ENABLED` 默认关闭。开启后复用现有 `LLM_API_KEY` / `LLM_BASE_URL`，独立审查模型为 `AI_MODEL_EXPERIMENT_REVIEW=deepseek-flash`，仅发送卡片截图及固定审查提示，不发送聊天历史、笔记、源码或工具权限。每条用户提问最多2次审查，失败/超时也占一次；每次最多1个HTTP请求，无自动HTTP重试、无重定向、连接3秒/读取15秒时限。审查结构、frame_id和问题区域均校验，拒绝、超时或无效结果都不挂载。审查期间参数版本改变，旧审查不能批准新参数；需要重新读取并检查。

视觉请求有独立观测项 `assistant.experiment.visual_review`，记录模型、帧数和token用量，不记录原图或凭据。该请求不属于DSH生成网关的6次请求额度；其额外上限为每条提问2次，正式启用前必须确认费用和真实接口验收。

提供 `unimind.chart(container, {type:'bar'|'line', labels, series:[{label,values}], xLabel,yLabel})`：平台负责图外图例、数轴、刻度间距、响应式重绘和数据点说明，模型负责选择图形、计算数据和交互逻辑。最多12个类别、3组系列，支持负值；稠密横轴可省略部分刻度文字，悬浮说明保留完整类别与数值。不是固定债券题模板，特殊图形仍可自由编写并走同一审查。

本地真实浏览器合成样例已产出6帧并通过柱状/折线切换与指定价格检查。模拟接口冒烟覆盖视觉拒绝不落卡、通过后保存、不留原图、审查预算耗尽、异常响应/超时，以及参数并发变化。上述不证明真实视觉模型的识别能力；真实接口调用及DSH自主生成/纠错验收单独记录，默认开关在验收前保持关闭。
