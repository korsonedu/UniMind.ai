# 国际化第一阶段

本地实现于 2026-11-15，尚未部署。范围是中英文基础和核心个人学习路径，不代表已完成海外商业上线。

## 已实现

- `frontend/src/i18n/` 提供 `zh-CN`、`en` 两种语言，无新增运行时依赖。默认按浏览器语言选择，用户可在登录／注册页、首页和「设置 → 外观与阅读」切换。
- 偏好保存在当前浏览器的 `unimind-language` 中，刷新后保留，同源标签页同步。语言切换订阅状态变化，不通过刷新或重新挂载工作区实现，不清空当前输入。
- 英文文案覆盖账号表单、应用导航、设置主体、小宇入口、会话／项目管理、学习安排／任务／知识与资料面板、内联练习卡片、个人笔记主要操作和常见账号／网络错误。
- 首页外层介绍和下载入口已迁移；演示图片和内嵌展示场景仍包含中文。
- 界面所用的日期、额度恢复时间按设备本地时区显示，金额按选择的语言格式化，原人民币币种和服务端额度恢复规则保持原样。
- Axios 与 SSE 请求携带 `Accept-Language`。用户提问保存 `metadata.ui_language`，普通请求、流式请求和 DSH 对话在服务端按本人消息取得语言偏好，再追加语言指令。明确的学习语言请求优先于界面默认语言，原文引用、代码和协议字段不翻译。
- 新会话标题支持英文最多 80 字符；中文仍最多 15 字。标题提示词统一放在 `backend/prompts/ai_assistant/`。

## 维护方式

组件调用 `useLocale()` 订阅语言切换，再用 `t('中文原文')` 取得界面文案；英文对应文本放在 `frontend/src/i18n/en.ts`。带变量的完整句子使用 `t('第 {0} 题', { 0: number })`，避免把一个句子拆成多个片段。

模块级固定菜单、枚举标签在渲染时调用 `t`，不能在模块初始化时缓存翻译结果。用户笔记、项目名称、历史消息、站内课程和原文引用作为内容保留，不做自动翻译。尚未迁移的文案回退到中文。

## 本轮验证

前端 TypeScript 与生产构建、Django system check 通过。使用本地示例数据的浏览器冒烟通过英文登录／注册、切换语言保留表单、刷新保存偏好、设置和小宇入口，以及 390 像素移动登录布局；跨标签页切换语言后，对话草稿、笔记正文和编辑器实例保持不变，无页面运行异常。后端冒烟验证请求语言归一化、按本人消息读取语言上下文、语言优先级提示及中英文标题限制。

浏览器示例数据仍为中文，未自动翻译；上述检查没有调用真实模型，不能据此宣称英文教学质量或海外访问已经验证。
