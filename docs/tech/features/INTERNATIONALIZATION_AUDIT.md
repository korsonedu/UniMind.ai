## 查漏发现并修复

1. 计费、支付结果、诊断、成就、404、预览组件、通知和若干公共控件仍含固定中文，现已补齐。
2. 笔记保存状态先翻译再参与中文比较，导致未保存提示不可靠；现保留源状态，只在显示时翻译。
3. 纯日期通过设备时区格式化，在美洲会提前一天；现固定纯日期，真实时间戳继续使用设备时区。
4. 知识关系节点按中文六字截断，会截掉英文单词；现英文按词分为最多两行，完整名称保留在提示和无障碍标签。
5. 原生 IPC 错误和认证／离线请求漏传语言；现统一处理，原身份、来源和权限校验保持不变。
6. 账号 HTML、服务端字段校验、DSH 流式步骤和异步通知遗漏语言；现分别使用请求或收件人偏好。提醒任务同时修正配置模型导入路径。
7. 首页英文模式仍使用中文截图；现用当前源码与虚构英文资料替换，并重置语言切换时的装饰截图缓存。
8. PDF 与课程笔记生成仍有固定中文标题，异步笔记摘要没有默认输出语言；现补齐，原文／证据／时间定位链接保留。PDF 下载名使用标准 UTF-8 响应头。

## 本地验证结果

仅做构建、静态查漏和针对性冒烟，没有运行完整测试套件，也没有发送真实邮件／通知、调用真实模型或支付。

- 前端 TypeScript 与生产构建通过；Electron TypeScript 和主进程打包通过。
- Django system check 通过；`makemigrations --check --dry-run` 无缺失迁移。
- 扫描前端和 Electron 所有字面量 `t`／`nt` 调用，缺失英文键为零；英文词典 2,849 项，占位符一致。
- AST 残留扫描后，生产界面未包装的中文 JSX 文本仅语言选项「简体中文」，按语言原名保留。动态菜单、状态源值、实体名称、协议标识和开发页面另行核对。
- 服务端提取的 547 个固定错误／消息候选均有英文登记；动态变量按完整模板匹配，不批量翻译任意正文。
- 浏览器冒烟通过补齐页面、设置搜索、语言切换／刷新／账号恢复、元数据／PWA、截图中英文切换和 390 像素布局，无页面异常。
- 既有跨标签页草稿／笔记、视频元素与已选答案保留检查通过；纯日期及真实时间戳在洛杉矶时区分别核对。
- 本地虚构英文资料通过知识图标签边界和练习提交／结果冒烟；首页图像不是实际学习效果证明。
- 原生离线库／播放器模拟检查通过中英文、插值、课程标题转义、CSP 和不可用课程提示；未替代真实安装包验证。
- 后端冒烟通过中英文错误、账号表单／校验、请求头／Cookie 优先级、同步和异步客户端、本人资料字段白名单、通知／邮件收件人语言及用户内容保留。
