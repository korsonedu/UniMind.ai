# 笔记的无感理解与小宇 @ 引用

日期：2026-10-24。状态：对话中的产品方向已确认，本文整理交互与实现边界；属于设计交付。

## 已确认的方向

学生基本不需要 AI 帮忙写笔记，但希望 AI 自然了解自己在写什么。笔记页专注编辑和组织，小宇在后台理解保存后的内容。学生无需选择 Agent、管理会话、添加参考或设置长期关联。

学生在小宇聊天页可以主动用 `@` 选择笔记，明确当前讨论重点。选中一次后，当前会话持续可参考；新会话清空；输入框上方保留可移除的笔记标签。每次提问读取最新已保存版本，历史回答保留当时使用的引用。

AI 始终只读。正文、标题、目录和标签均由学生编辑。日常不弹建议、不插话，不自动把聊天内容写入笔记。

本设计替代 `2026-10-22-agent-linked-notes-design.md` 中面向学生的笔记内讨论面板、Agent 选择和手动长期绑定流程。私人笔记、所有者隔离、版本冲突保护、历史来源等既有约束继续保留。

## 学生实际看到什么

### 笔记页

保留现有编辑器、多级笔记本、标签、搜索、收藏、双向链接、回收站与导出，以及必要的保存状态和错误反馈。沿用已确认的单编辑器、图标工具栏、站内弹窗和简洁文案。

移除笔记侧的 AI 讨论区域及相关入口，移除 Agent 选择、会话管理、本次参考、长期关联及选中文字发送讨论的入口。手机端仅切换目录和笔记。

学生照常打开、书写和整理笔记。后台理解不会占用输入焦点或阻塞保存，也不需要学生等待“AI 分析完成”。

### 小宇聊天页

输入 `@` 时弹出自己的可用笔记列表，继续输入文字搜索标题。结果展示标题和所属路径，以区分重名笔记。第一版只选择单篇笔记，允许多选；不增加 `@笔记本`、新指令菜单或引用范围设置。

选择结果后，输入框上方出现笔记标签，搜索片段从问题草稿中移除，学生继续正常输入问题。支持键盘选择、确认和关闭，也可直接触摸选择；移除标签有可访问的按钮。`@` 没有选中结果时不会被当作已关联笔记。

例如选择“债券定价”后输入“这里为什么用到期收益率折现？”。学生发送问题后，标签继续保留，后续可以直接追问“第二个公式呢”。切换已有会话恢复那个会话的标签；新建会话从空标签开始。

消息中保留发送时的笔记附件记录，点击可以打开原笔记。回答中的来源引用继续区分实际提供的材料与模型明确引用的材料。

## 两种理解如何配合

自动理解负责日常连续性，`@` 提高选中笔记在当前会话中的参考优先级。`@` 不创建永久绑定，也不决定 AI 唯一可了解的笔记范围。

取消标签表示取消当前会话的重点参考。自动理解仍按学生的笔记使用设置生效；取消标签不等于让小宇遗忘旧回答。界面不为这些规则增加常驻说明或额外配置表单。

第一版先供这名学生自己的小宇使用，不把笔记理解写进共享 Bot 的全局提示或其他 Agent 的通用记忆。机构角色也不会因此获得学生私人笔记权限。

## 后台理解与使用

以下为实现建议，学生无需操作这些步骤。

1. 标题或正文稳定保存后，后台对该版本进行理解。复用现有异步任务设施，对频繁更新合并、去重，只让最新有效版本成为当前理解；不逐键调用模型。
2. 记录内容涉及的主题、学生明确写下的解释、提出的疑问和可追溯的学习线索。明确区分原文证据与 AI 推断，不把摘录过某知识点直接视为已经掌握。
3. 每条理解保留用户、笔记 ID、内容版本和原文依据。原文仍是权威数据，理解结果是可更新的派生数据，不能反写笔记。
4. 小宇收到问题时，按相关性读取有限的理解与笔记片段；`@` 的笔记优先。不会在每条问题中塞入全部笔记，也不声称读完了未提供的内容。
5. 正文修改后更新理解；回收、永久删除或关闭笔记 AI 使用后，相关内容和派生理解停止参与后续装配。历史消息与引用保留历史属性。

第一版的可见收益以小宇后续聊天能自然接上笔记中的思路为主。笔记形成的学习线索单独保存，小宇的个人上下文可以读取，不合并进所有 Agent 共用的画像字段或通用记忆。需要在画像中呈现时，按有效来源实时读取这些线索，而非复制成无法追溯的长期结论。笔记修改、删除或关闭自动了解后，旧版本线索及依赖它们的笔记推断一并失效，其他证据不受影响。涉及掌握程度、薄弱点等判断时结合做题与交流表现。具体呈现方式留待实现计划核对，不新增学习评分或自动创建今日任务。

笔记理解任务失败不影响编辑和保存，保留待处理状态以便重试。旧版本结果不能覆盖新版本结果，失效笔记不能因排队任务完成而重新进入参考范围。

## 透明性与数据边界

采用此前建议的首次使用说明和个人设置中的统一开关，说明小宇会了解自己的笔记；日常编辑不反复提示。实现建议：新用户与既有用户在首次确认启用前均不进行后台读取；首次进入笔记时仅说明一次，学生可启用，也可直接开始普通书写。确认启用后，后台分批理解其当前有效笔记，之后自动处理保存的更新。关闭后重新启用则重新核对当前版本。开关仅控制自动理解，关闭后笔记本身仍可正常编辑。

关闭后不进行新的自动理解或自动装配，旧派生理解标记失效。学生仍可主动 `@` 授权当前会话参考选中的笔记，这不会重新开启后台理解或生成持久学习线索。设置关闭期间无需在笔记页常驻提醒。旧手动绑定不视为已经授权后台理解全部笔记，启用记录与手动会话引用分开保存。

所有读取继续校验当前用户、笔记可用性、小宇使用资格及会话归属。笔记正文只作为参考材料，不改变系统指令或授予写入工具。其他人的笔记、回收站内容、失效派生数据和无效引用 ID 都不能进入参考范围。

## 与现有实现的衔接

- `NotesPage.tsx` / `NoteEditor.tsx`：删除侧边 AI 面板与文字选择讨论接入，保留编辑、保存、导航保护和本次图标/弹窗优化。
- `AgentChatLayout.tsx` / `useAgentConversation.ts`：在小宇现有输入器中接入 `@` 搜索、笔记标签、发送前校验和会话恢复，不再建立新的聊天页面或状态体系。
- `ConversationNoteReference`：复用其用户、小宇、会话、笔记关系，表达当前会话的重点参考；区分“省略列表沿用”与“显式空列表解除”。
- `notes/context.py`：从目前手动绑定的范围装配，调整为经统一设置允许的本人笔记自动相关检索与会话重点参考；普通 Agent 的范围不被自动扩大。
- 自动理解结果保留版本和依据，通过专门的小宇笔记上下文入口使用。原有“笔记对话不进入通用自动记忆/跨 Agent 轨迹提取”的保护继续保留，不能靠取消保护来实现后台了解。
- `AIChatMessage.metadata` / `NoteSources.tsx`：继续保存真实来源快照，补充用户主动关联的附件记录。历史消息不随笔记改名、改写而变成新版本材料。
- 既有 `AgentNoteBinding` 先保留兼容与数据，不在此次设计中要求删表。学生无需维护这些绑定，小宇的自动了解也不受旧手动绑定是否存在的限制。

具体模型字段、队列去重方式、检索预算及后台用量处理留给实施计划，复用现有设施，不建设新的知识库平台或通用 RAG 服务。

## 验收场景

只做必要冒烟，使用本地隔离账号和数据：

- 笔记页没有 AI 配置和聊天面板，桌面与手机端均可正常编辑、保存、重开。
- 写入并稳定保存一条带明确疑问的笔记，不做关联操作，小宇之后的相关问题能获得对应的有效学习线索和来源；无关问题不硬塞笔记。
- `@` 搜索、重名选择、多篇标签、取消、发送和追问可用；切换会话恢复各自标签，新会话为空。
- 标签移除后不再作为重点参考，自动了解仍按统一设置生效；关闭设置后自动了解停止，主动 `@` 仍可用于当前会话。
- 修改笔记后新请求取得最新版本，迟到理解结果不会覆盖新版本；回收或删除后停止使用，历史引用仍显示原版本属性。
- 用户隔离、会话归属、Bot 权限、无效来源和只读边界均保持；自动理解失败不影响保存，不泄漏到其他 Agent。
