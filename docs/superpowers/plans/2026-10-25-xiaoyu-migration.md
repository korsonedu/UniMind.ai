# 小宇能力迁移与服务端 harness 基线

日期：2026 年 10 月 25 日。盘点基线：c42583c。本文区分现有源码、已验证 M0 与目标能力，不作为上线声明。

## 产品与部署决策

DSH 是 UniMind 服务端 Agent harness。UniMind 自己定义 React 学习界面、账号、权益、课程、题库、记忆和教学流程。网页、移动网页和薄桌面客户端经统一 AI 接入层访问服务端隔离 Host/DSH；桌面不内置 DSH。安装包、登录和系统集成放到 M2，不再阻塞 harness 迁移。

完整目标规划为 /Users/eular/Desktop/科晟开发/UniMind/规划/2026-10-25-新UniMind完整规划-v1.2.md。原 v1.1 保留作历史对照。开发机的 127.0.0.1 Host 是服务端组件的单机原型；尚未接入站点身份、多用户隔离与生产托管。

## 迁移原则

保留小宇业务能力和权限语义，逐项替换旧模型编排。工具进入候选、通过执行鉴权、完成业务任务是三个不同验收结果。不能只注册工具定义就宣称迁移完成；当前正式小宇入口保持原路径。

当前源码学生目录为 7 个基础工具加 18 个规划工具，共 25 个；工作台另有 12 个定义，分属不同角色。新学生目录明确排除 save_session_note。截至 2026 年 10 月 26 日，本批已开放 17 个只读工具并接通结果卡片；写工具及剩余查询继续后置。

## 编排与辅助能力

| 人设、学情上下文、经验、动态指令 | 保留教学语义并逐项适配 | M0 提示词为最小版本，不代表完整旧提示词/经验链已迁移 |
| 结构化学生事实记忆 | UniMind 管理，插件读取 | M0 AgentMemory 已接通；更正/删除后运行上下文失效 |

| ASR、Embedding、检索与搜索 | 受控基础服务，单独核算 | 网页搜索正式来源尚未接入；语义路由真实质量未验证 |
| 标题、摘要、记忆提取、教研生成 | 逐项移交 DSH | 零散旧调用仍需盘点与切流，不能绕回旧 AIEngine |

本批实现与证据：

- Cordis 插件迁为 plugin.ts，保留 name、inject、apply(ctx: Context)。锁定 SDK 0.2.1rc2 的实际运行时直接加载 TS 源码；没有通过修改后缀来代替加载验证。Python 只承担 Django 业务与开发 Host/网关。
- 根据官方工具参考，output.render 与 UI 展示分别处理。原生 output.presentationMeta 把 unimindCard 持久化为 tool/result.data.meta，模型仅接收去掉 visual 的业务数据；Host 只读取经过许可调用关联的成功事件元数据。没有建设第二套模型驱动的渲染协议。
- 4 项后端定向冒烟通过，覆盖 17 个工具、本人/他人数据、平台/私有内容、参数和记忆版本边界，以及报告统计单位；12 项 Host/会话/网关/卡片本机冒烟通过。未运行全量回归。
- 实际 DSH、实际 Django 临时 SQLite 与确定性 SSE 夹具完成八个工具往返，产生 data_card、knowledge_map、practice_result、question_preview 四类卡片；预览不含答案，模型请求不含 UI visual。两个 Host 解释器进程恢复会话及卡片，记忆更正/删除后上下文重建通过。此处工具调用由夹具固定，不能作为意图路由准确率证据。
- 前端类型检查与生产构建通过；浏览器实际运行后显示八张卡片，刷新恢复同一会话。页面实时显示目录 24、候选 21、可执行 17、待迁移 4，候选 Schema 15912 bytes，实际开放 10438 bytes；不将扩容后的上下文成本写成路由优化。截图 .m0-state/m0-native-results-proof.png 与 .m0-state/m0-native-cards-proof.png。

本批采用的边界：复用原 PracticeQuizCard 会触发写路径，因此只接题目预览，完整作答/批改仍待迁移；讲稿时间戳先作为来源文字，播放定位未验收；文章目的页已退出，资料检索后置；知识查询既有经验触发时间记录保留，不重写经验系统。代价分别是本批不能验收完整练习、时间点直达、资料检索和完整旧经验链。
