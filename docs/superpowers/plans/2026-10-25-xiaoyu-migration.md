# 小宇能力迁移与服务端 harness 基线

日期：2026 年 10 月 25 日。盘点基线：c42583c。本文区分现有源码、已验证 M0 与目标能力，不作为上线声明。

## 产品与部署决策

DSH 是 UniMind 服务端 Agent harness。UniMind 自己定义 React 学习界面、账号、权益、课程、题库、记忆和教学流程。网页、移动网页和薄桌面客户端经统一 AI 接入层访问服务端隔离 Host/DSH；桌面不内置 DSH。安装包、登录和系统集成放到 M2，不再阻塞 harness 迁移。

完整目标规划为 /Users/eular/Desktop/科晟开发/UniMind/规划/2026-10-25-新UniMind完整规划-v1.2.md。原 v1.1 保留作历史对照。开发机的 127.0.0.1 Host 是服务端组件的单机原型；尚未接入站点身份、多用户隔离与生产托管。

## 迁移原则

保留小宇业务能力和权限语义，逐项替换旧模型编排。工具进入候选、通过执行鉴权、完成业务任务是三个不同验收结果。不能只注册工具定义就宣称迁移完成；当前正式小宇入口保持原路径。

当前源码学生目录为 7 个基础工具加 18 个规划工具，共 25 个；工作台另有 12 个定义，分属不同角色。新学生目录明确排除 save_session_note。M0 仍只执行已验证的 5 个只读工具，其余仅参与迁移盘点和候选对照。

## 编排与辅助能力

| 能力 | 处理方式 | 当前边界 |
|---|---|---|
| 身份、权益、工具/内容鉴权 | 留在 UniMind 后端，调用前再次验证 | M0 复用现有过滤和执行器；正式新权益仍待 M1 |
| 工具候选路由 | 复用现有 route_tools 的关键词、上下文、工作流与大目录语义检索入口 | 新路径显式使用确定性分类，不触发旧 AIEngine |
| 模型意图分类 | 如需要则迁移为受限 DSH 分类任务 | 尚未接入；不能宣称与旧 LLM 分类质量等价 |
| 工具与模型循环、会话历史 | 交给 DSH；Host 适配 UniMind 协议 | SDK、原生恢复和记忆失效已在隔离数据上验证 |
| 人设、学情上下文、经验、动态指令 | 保留教学语义并逐项适配 | M0 提示词为最小版本，不代表完整旧提示词/经验链已迁移 |
| 结构化学生事实记忆 | UniMind 管理，插件读取 | M0 AgentMemory 已接通；更正/删除后运行上下文失效 |
| Memorix 复习模型 | 留在确定性学习业务 | 不并入事实记忆，不因使用 DSH 重写 |
| ASR、Embedding、检索与搜索 | 受控基础服务，单独核算 | 网页搜索正式来源尚未接入；语义路由真实质量未验证 |
| 标题、摘要、记忆提取、教研生成 | 逐项移交 DSH | 零散旧调用仍需盘点与切流，不能绕回旧 AIEngine |
| 配额与费用结算 | 留在可信服务端 | 当前只有本地单任务技术预算和 usage，未接正式周期扣费 |
| 流式消息、来源、结果和练习卡片 | 保留 UniMind React 组件，新增 DSH 事件适配 | 当前开发页仅展示文本与诊断信息，正式卡片链路未迁移 |
