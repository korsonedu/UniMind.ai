# UniMind 统一版本实施计划

**目标：** 落实用户已确认的共用版本序列，准备 1.4.0「小宇随课问答」。

**实现：** `frontend/package.json` 是唯一手动版本来源；桌面编译前同步包元数据和锁文件。Vite 分别注入产品版本和构建 SHA，设置页保留真实安装版本。

**约束：** 最小修改；仅冒烟；不改旧标签、安装包及无关文件；本轮完成本地准备，不自动部署或分发。

- [x] 更新前端版本、Vite 注入和桌面同步脚本。
- [x] 设置页展示产品、客户端版本及技术详情。
- [x] 发版提醒限定产品标签，不按提交数自动决定版本类型。
- [x] 补齐 VERSIONING、桌面发行说明和待发布 CHANGELOG。
- [x] 前端构建、桌面编译／类型检查、发版脚本冒烟与差异检查。

**检查重点：** 旧客户端显示真实版本；桌面标签不影响产品版本；CI 能读取统一来源；锁文件无依赖漂移；待发布状态不冒充上线。

**验证结果：** 前端生产构建、桌面编译及类型检查通过；版本同步冒烟验证旧版本更新、依赖保留和重复执行稳定；发版提醒与差异检查通过。独立只读复核未发现阻塞问题。没有部署网页、生成新安装包或修改已有标签。
