# UniMind DSH 迁移状态

更新：2026-10-27。本文记录代码路径和本地证据，生产部署另行验收。

## 产品与运行位置

UniMind 保留现有 React 学习界面和 Django 业务。DSH 是服务器上的 AI harness。浏览器和已构建的 Tauri 薄桌面候选只访问 UniMind API，不安装 DSH，不获得模型密钥。课程播放、原业务详情、练习与真人答疑可以独立于 AI 会话运行。桌面与可重复预览的启动方法见 [PREVIEW.md](../dsh/PREVIEW.md)。

## 现有能力的去向

| 原能力 | 当前路径 |
| --- | --- |
| 小宇问答、学习与课程查询、Memorix 查询、自习查询 | 原 /xiaoyu 和 chat/stream → dsh_xiaoyu → 隔离 worker → TS 学习插件 → 当前用户业务回调 |
| 练习抽题与作答 | 查询只返回题目；原 PracticeQuizCard → submit-exam → 原事务和后台评分 |
| 换设备恢复已交卷练习 | GET quizzes/submissions/<uuid>/ 仅返回本人的原考试编号和作答，卡片读取原成绩，不再次提交或评分 |
| 首次诊断 | 模型仅准备卡片；学生确认后按数据库答案评分并初始化 Memorix |
| 人工答疑 | 模型仅准备可编辑草稿；学生确认后进入原 faq_system，通知不自动发送 |
| 主观评分与客观解析 | 原 AIService → 专用 DSH collector；客观题仍由服务端答案比较决定分数 |
| 教研解析、Author/Reviewer/Revise/Classifier、批量与配套题生成 | 原教研任务和管线 → DSH collector；Reviewer 可使用原只读研究工具，候选仍须人工审核入库 |
| 教研聊天、学生详情/报告、通知和精修准备 | 原后台任务 → DSH 工具组和受控 TeachingExecutor；通知、精修、入库仍须原后台确认 |
| 标题、长期记忆提取 | 专用 DSH 任务，固定预算；无合格稳定事实时返回空记忆候选 |
| 笔记理解、课程辅助、参考解析、知识树/语义边、经验与画像分析及题目考点回填命令 | 生成总开关开启后，统一经 AIService/AIEngine 进入 DSH；原后处理和权限边界保留，维护命令不再直接请求模型 |
| Embedding、向量检索、ASR | 保留原非生成服务边界，不冒充 DSH 生成任务 |

学生原目录 25 个工具中，21 个已接入。其余四个明确处理如下：save_session_note 停用 Agent 写笔记；grade_student_answer 的自由写分路径停用，使用学生提交后的原评分；render_visual 停用任意模型卡片，改用可信工具结果的原生 presentationMeta；search_articles 的学生旧文章页面已经退出，内容由后台 list_articles/内容浏览保留，不向学生返回失效的 /article 链接。不能将这四个列为待直接注册的工具。

## 开关与失败行为

服务器先配置既有 UNIMIND_DSH_ENABLED、UNIMIND_DSH_SITE_ENABLED、UNIMIND_DSH_XIAOYU_ENABLED，以及独立 SDK Python、固定 loopback API 地址和私有状态目录。生产前执行已有迁移，尤其 0031 记忆来源记录和 0032 学生确认记录。

- UNIMIND_DSH_TEACHING_ENABLED：教研解析、出题/评阅管线、参考解析与后台教研聊天。
- UNIMIND_DSH_GENERATION_ENABLED：剩余内部生成任务全部进入 DSH；同时强制标题、记忆和评分使用已有专用通道，避免另走宽预算。必须在正式小宇服务端入口已配置后开启；旧流式 Agent 被明确拒绝，不静默切换供应商。
- 原 TITLE/MEMORY/GRADING 独立开关仍可用于分项启用。总开关关闭时，它们继续独立生效。

以上默认关闭。本轮没有修改实际 .env 或启用生产开关。DSH 已选中后，失败不调用旧 AIEngine 供应商路径；原任务记录失败，学生原作答和管理员材料保留。回退是显式关闭相应开关后的整体选择，不是在同一任务中混用两个引擎。

教研研究工具最多 6 个，加发现工具和最终 collector 后最多 8 个。每次生成按原 operation 选择 fast/pro、thinking 和 temperature；无研究工具时一次模型请求，有研究时最多 8 次；最多 8192 输出 tokens、65536 请求 bytes。整条多阶段管线的累计请求不等于单次生成预算。专用评分、标题和记忆维持各自更小预算。四个运行槽位共用，嵌套生成也占槽，不声称已验收生产并发。用量审计记录原 operation、模型、等级和 tokens，不保存正文或凭据。

教研任务每次生成、研究回调、进度更新及保存候选前复核当前管理员、任务状态和内容范围。聊天内的嵌套生成共用外层 90 秒截止时间；关闭回调时取消后续生成，正在进行的子进程按同一截止时间终止并清理。撤权、超时或晚到结果不会落入候选。生成总开关也在 mem0.add 边界关闭旧自动提取，保留原语义检索。

## 会话、删除与遗留数据

产品对话和正式成绩仍在 Django；原生 DSH home 仅保存该用户运行上下文。本人服务端会话可读取、导出和删除；状态跨端以服务端身份为准。网页退出/切换账号清理当前会话状态，浏览器草稿按用户隔离。

删除正式小宇会话会清理对应运行 home 与缓存回答，并将额度记录保留为已删除 tombstone；标题和记忆任务在写回前检查来源，晚到结果不能重建已删内容。长期记忆独立更正/停用/删除，版本改变使旧原生上下文失效。成绩、已确认答疑和用量不随清空聊天消失。旧对话保持可读，不假设能直接导入原生 DSH Session；机构历史保留，当前学生权限和后台内容范围继续由现行单平台规则决定。

正式 180 天提醒/30 天导出期等仅为原规划建议，尚未获确认；没有新增定时永久删除，也没有用无限期保存作为已批准的产品政策。账号注销、备份重放删除和跨节点恢复需要在真实学生切流前验收。

## 本地证据和交付边界

一份必要API冒烟覆盖注册/课程学员、列表/详情、嵌套专辑、直接文件、匿名与生成限制，前端构建通过。实际网页用合成注册账号只显示公开课，5秒本地视频完整播放，直达私有课显示未找到；同账号一次真实DeepSeek问答额度13→12。截图位于 `.m0-state/m0-public-course-{list,playback,denied}-proof.png` 和 `m0-registered-chat-proof.png`。不将合成视频当作正式课程内容或真实学生交付证据。
