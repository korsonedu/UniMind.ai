# 小宇迁移与 Electron 能力核对

2026-10-29，实施后复核 `codex/unimind-dsh-m0` 当前源码与既有本地证据；不代表已验证生产开关或完成平台发布。

## 小宇是否完整迁移

结论：主干业务、受控展示与工具进度已接入 DSH；真实模型效果和生产开关仍须发布验收。

通过 AST 比较 `backend/ai_engine/tools.py` 的原 planner 工具目录与 `backend/ai_assistant/services/dsh_service.py` 的允许列表：原 25 项，DSH 注册 21 项。课程／讲稿／知识点、练习／错题／复习、学习记录／统计／报告／成就、自习、首次诊断和人工答疑均有业务入口；调用仍经当前用户鉴权。

| 原能力 | 当前处理 |
| --- | --- |
| save_session_note | 有意退出 Agent 写笔记，保留用户编辑、笔记引用与授权阅读 |
| grade_student_answer | 不再允许模型自由提交评分，改由学生提交后的原考试／专用评分通道处理 |
| create_faq_ticket、run_diagnostic | 保留，但改为先准备卡片，由学生自行作答或编辑并明确确认 |
| search_articles | 学生旧文章入口退出；不返回失效链接 |
| render_visual | 任意模型卡片退出；业务卡片来自可信工具，展示卡片经独立 Schema 校验 |

其余 4 项不应简单计为漏迁。当前已补齐展示和进度缺口：

- `present_learning_visual` 独立展示工具支持公式推导、解题步骤、函数采样点与回复选项。服务端限制字段、数量、大小、有限坐标与内部导航；DSH 不执行模型表达式、HTML 或脚本。
- `tool_status` 经正式 SSE 转换为带稳定 `call_id` 的步骤事件；成功、业务失败与中断均有终态。最终卡片仅存入消息 metadata，历史重读不重复生成。
- 原 21 项业务工具和已有确认边界保留。笔记由用户编辑、评分经学生提交、诊断与答疑先展示确认卡。
- 标题、长期记忆、评分与内部生成仍分别受服务端开关控制。不能以代码存在推定生产全开；没有进行真实模型质量验收或历史数据批量转换。

## Electron 桌面优势是否已有

结论：桌面功能链路已接入，限定范围的冒烟通过；产品验收尚未全通过。正式发行证据和离线学习、下载恢复、任务恢复等体验仍有缺口，详见 DSH_DESKTOP_ACCEPTANCE_2026-10-29.md。

| 能力 | 当前状态和依据 |
| --- | --- |
| 原生窗口、标题栏、菜单、单实例、macOS 回弹 | 保留既有能力 |
| 系统通知 | 小宇完成与未读新增可通知；默认关闭，主窗口聚焦时抑制，点击回到应用 |
| 菜单栏／托盘驻留 | 显式开启后关窗隐藏，保留渲染进程和下载；菜单可退出 |
| 专用快捷键、深链接 | 菜单快捷键与 `unimind://settings|xiaoyu|courses|notes`；拒绝 token 注入和外部站点导航 |
| 课程下载与离线观看 | 课程页下载、设置页进度／重试／移除、独立本地课程库与 Range 播放；按账号隔离，联网复核授权／视频版本 |
| 离线期限 | 最多24小时；私有课程同时受批次到期限制。退出账号清除缓存，撤权／切账号／到期中断播放 |
| 自动更新 | 正式签名包可配置固定 HTTPS 发布源；预览包禁用，未配置明确显示。尚未验收真实更新安装 |
| 登录回流 | 现有同 session 登录保留；外部账号中心的授权码交换尚未提供，未伪造跨浏览器登录回流 |
| Windows 发布 | 保留 NSIS／CI；本轮未验证 Windows 实机安装、系统通知或升级 |

签名证书、可信更新源、macOS 公证与 Windows 实机验收属于正式发布条件，未完成不能标记为生产发行就绪。

## 设置页调整

沿用 React 与现有 API，按用户 Codex 截图改为左分类／右分组的设置工作区。网页分类为个人资料、外观、笔记与小宇、账户安全、数据管理；Electron 另有桌面应用分类，保留我的服务入口；设置搜索只过滤现有能力。保留昵称、简介、头像风格与特征、外观、笔记授权、邮箱／密码、数据导出和注销。

移除旧页面的多列大卡片及化身侧滑层；注销改为页内密码确认，不自动提交。页面沿用当前主题和焦点样式；窄屏使用可横向滚动的分类导航，内容独立滚动。

类型检查和前端构建通过；本地合成学员页面验证分类、搜索、笔记授权读取、注销确认打开与取消。320px 下页面无横向溢出，输入为 16px，正文区域可独立滚动；深浅色切换均已查看。未更改账号密码、邮箱或注销真实账号。系统通知与关窗驻留默认关闭，由用户选择开启。

## 本轮验收边界

前端与Electron构建通过，后端仅定向冒烟。独立macOS Electron预览中已核对桌面设置、未配置更新源、独立离线库及合成公开课下载、独立本地视频播放与设置页下载管理；默认通知／驻留保持关闭。原生进程冒烟覆盖Range读取、断网HTML、复连撤权及退出清理。签名公证、正式更新源、外部登录授权交换与Windows实机尚未完成，不能据此宣称已正式发行。
