# UniMind — Agent 驱动的新一代智能教育基础设施

> 本文面向潜在客户与合作伙伴，介绍 UniMind 的产品理念、核心功能与商业方案。系统架构与算法细节见上级目录 [UniMind系统介绍.md](../UniMind系统介绍.md)。

UniMind 是一套面向教育培训机构的 AI 基础设施。两个自治 AI Agent——学生学习教练「小宇」与教师教研助手「工作台」——覆盖从出题、刷题、批改到记忆调度的全链路。底层为四层自适应学习架构，内置 13 学科 4,486 知识点的全景知识图谱。B2B 机构部署，数据完全隔离。

---

## 一、产品理念：不是菜单，是对话

UniMind 与「菜单驱动 SaaS + AI 聊天框」的架构逻辑相反：**Agent 是入口，SaaS 是画布。**

学生登录后首先面对的是小宇——小宇根据记忆模型推送该做的题、提示该复习的知识点、展示掌握度热力图。学生不需要知道"题库""错题本""知识图谱"这些功能的名字，小宇在对话中调出对应的卡片和面板。教师同理——工作台是对话式指挥中心，"出 5 道极限计算题"一句话触发完整的出题管线。

> 传统：功能模块 → 用户自学菜单 → 手动操作
> UniMind：Agent 理解意图 → 编排工具 → 对话中交付结果

这带来两个根本差异：

**系统能力的边界不取决于功能菜单的数量。** 传统 SaaS 每增加一个能力，需要新页面、新按钮、新引导流程。UniMind 每增加一个能力，只需给 Agent 注册一个工具。能力增长体现在 Agent 工具箱的扩展，而非菜单膨胀。

**用户不需要自行决策。** 传统 SaaS 中学生需要判断"我该去错题本还是做练习题"——这需要自驱力和判断力。在 UniMind 中，小宇基于记忆模型替学生做了这个判断——"三角函数你有 3 道到期题，上次导数正确率从 40% 升到 65%，今天继续？"学生回应一句话即可。

## 二、为谁解决什么问题

### 学生：不再遗忘，精准提升

**Memorix 记忆调度**为每道题独立计算遗忘曲线，在临界点自动推送复习。学生打开小宇时面对的永远是当前最优的练习组合，而非盲目刷题。

**错因诊断**自动归类为概念错误、计算失误或粗心，三种错因触发不同的再巩固策略。IRT 模型给出标准化能力值，而非粗糙的正确率百分比。

**主动推动**——即使学生不登录，到期题目超阈值时自动推送通知。系统替学生记住该做什么。

### 教师：从 2 小时到 5 分钟

**对话式出题**——一句话生成题目，ARC 四 Agent 对抗管线将单次通过率从 60% 提升至 85%+。题目卡片实时展示进度（"评审第 2/6 题"），精修题带紫色来源徽章，一键入库。

**作业批改减负**——客观题自动判分，主观题提交后教师可一键触发 AI 批改，逐题复核后发布。一个 30 人班级的批改从 2 小时降到 15 分钟。

**学情可视化**——班级薄弱知识点分布、学生成绩矩阵、个体学习趋势，全部通过自然语言查询即时呈现。教师不需要学会操作任何数据平台。

### 机构：数据资产 + 续费提升

**续费率**——遗忘导致的挫败感是退课的首要原因。Memorix 驱动的主动复习直接提升续费率。

**教师产能**——出题和批改释放的时间用于答疑和个性化辅导，提升服务深度。

**数据沉淀**——每个学生的记忆模型、IRT 能力值、知识点掌握图谱随使用积累。教师离职不带走数据——教学资产留在系统里。

## 三、使用场景

### 学生的一天

小宇检测到 5 道三角函数到期题。学生打开 UniMind，小宇已在对话中："三角函数 5 道到期题，上次正确率 60%，现在复习？"学生回复"好"。做到第 3 题出错——小宇归类为概念错误，展示解析后匹配一道相近难度变式题。做完后展示今日学习摘要和掌握度变化。全程不需要点击任何菜单。

### 教师的一天

教师打开工作台说"出 3 道极限计算题，中等难度，给火箭班做练习"。工作台搜索知识点、生成题目，展示预览卡片。教师确认后说"入库，发给火箭班"。第二天说"火箭班作业交了没"，工作台返回提交进度和待批改列表。教师一键 AI 批改主观题，逐题复核后发布成绩。

### 新机构接入

1. 注册机构账号 → 选择学科模板 → 30 秒完成初始化
2. 创建班级，邀请教师加入
3. 教师通过对话出题或导入已有题库
4. 学生通过邀请链接注册，完成诊断测试
5. 小宇即刻开始主动推送复习任务

14 天全功能试用，从注册到学生开始使用不超过一个工作日。

## 五、系统架构

UniMind 的四层架构自底向上逐层支撑：

**第一层 · 基础框架** — Agent 运行时基础设施。对话生命周期管理、Bot 注册与工具权限控制、意图预筛选路由、模型分级调度、WebSocket 与 SSE 传输。新增 Agent 只需注册 BotProfile 与工具集，自动继承上层全部能力。

**第二层 · 记忆系统** — 系统的有效性核心。为每位学生每道题独立维护记忆模型（stability、difficulty、next_review_at），Weibull 遗忘模型 + 在线 SGD 逐次更新。双层记忆架构：结构化 KV（AgentMemory）+ 语义向量检索（mem0 + pgvector）。MUTAR 自进化引擎采集对话轨迹 → 周期性分析 → 生成优化候选，人工审核后应用。

**第三层 · 教育闭环** — 教（知识讲解、资源推荐）、练（抽题练习、到期复习）、测（诊断测试、模拟考试）、评（自动批改、错因分析）四环节闭环。评测结果回流更新记忆模型，使用越久建模越准。

**第四层 · 认知诊断** — IRT 三参数 Logistic 模型，机构级参数隔离，MML-EM 参数估计。Fallback CTT 保证新题冷启动。

## 十、数据安全

- **物理隔离**：每家机构独立数据空间（记忆模型、IRT 参数、知识树、对话历史），互不可见
- **私有化部署**：Pro 方案数据不出机构内网
- **数据主权**：机构拥有全部数据的所有权和导出权
- **认证安全**：httpOnly Cookie + CSRF 保护，四层 RBAC 权限体系
- **AI 安全**：按任务粒度熔断保护，工具权限白名单审计

## 十一、常见问题

**Q: 现有题库可以导入吗？**
A: 支持 Markdown 格式批量导入，机构可混合使用系统预置和自有内容。

**Q: 教师需要培训吗？**
A: 不需要。工作台是对话式操作，首次使用有遮罩引导，新教师 5 分钟内掌握基本操作。

**Q: 学生水平参差不齐怎么办？**
A: 首次登录完成诊断测试，系统据此初始化个人记忆模型。后续所有训练基于个人模型调参，同班不同水平获得不同练习组合。

**Q: 支持哪些学科？**
A: 预置 13 个学科（金融 431 / CFA / CPA / 法考 / 法学 / 教资 / 教育学 311 / 计算机 408 / 高中数学 / 高中物理 / 高中化学 / 高中生物 / USMLE）。机构可导入自定义学科。

**Q: 支持哪些平台？**
A: Web 端全功能支持。飞书和邮件推送已上线。

**Q: 能换 AI 模型吗？**
A: 支持供应商热插拔（DeepSeek、OpenAI 等兼容接口），多模型分级路由允许不同任务使用不同模型。
