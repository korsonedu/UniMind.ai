# UniMind — 智能教育基础设施

UniMind 为教育培训机构提供 AI 驱动的教学基础设施。系统部署两个自治 Agent：学生学习教练「小宇」和教师教研助手「工作台」，覆盖从出题、练习、批改到记忆调度的完整教学闭环。

UniMind 的起点是一个简单的观察：传统教育科技产品完成了将纸面题目迁移到屏幕上的工作，但没有触及一个根本问题。学生的学习状态不是已做题目的列表，而是一组动态的记忆痕迹，每条痕迹有自己的衰减速率，需要在不同时间点被重新激活。一个无法建模这种状态的系统，本质上是一个题库。

这一判断决定了 UniMind 的架构选择。系统以记忆状态为时钟，将间隔重复调度引擎置于中心位置，而非作为附加模块。两个 Agent 共享统一运行时，学生和教师通过自然语言对话完成全部操作。底层为 ARCA 四层架构，内置 13 学科 4,486 知识点的全景知识图谱。机构间数据完全隔离。

## 一、系统架构

ARCA 是 UniMind 的架构骨架，四层自下而上逐层支撑。

**第一层：基础框架。** 这一层解决"如何让 Agent 稳定运行"的问题。包括对话生命周期管理、Bot 注册与运行时、工具注册与权限控制、意图预筛选路由、模型分级调度、WebSocket 与 SSE 传输。这些能力与教育业务无关，是任何 Agent 驱动系统都需要的基础设施。

框架层的核心设计是解耦。新增一个 Agent 只需注册 BotProfile 与工具集，自动继承上层全部能力，不需要重建对话系统或 API。小宇和工作台共享同一运行时，通过工具权限沙箱隔离各自可用的工具子集。意图路由器按关键词预筛选工具候选集，从 30 多项工具中精准定位当前场景所需，Local BGE 模型在 Django 启动时预加载。

**第二层：记忆系统。** 系统的有效性取决于这一层。它解决的核心问题是"系统对学生知道多少"。

传统系统只记录做对了几道题。UniMind 为每位学生每道题独立维护一个持续演化的记忆模型，包含记忆稳定性、题目难度感知和下次复习时机三个核心参数。Weibull 遗忘模型替代了 FSRS 的固定指数幂律，形状参数从数据中学习，在线 SGD 加 Nesterov 动量实现逐次答题实时参数更新。新用户从人群均值出发，逐步漂移到个性化最优。Brier Score 严格恰当评分规则确保预测概率收敛到真实概率。

双层记忆架构支撑这一层。结构化存储以 KV 形式精确记录用户偏好、学业状态和交互习惯，按置信度和使用频次排序注入 system prompt。语义记忆基于 mem0 和 pgvector 实现向量相似度检索，支持模糊语义匹配，按机构分 collection 隔离。双层互补：结构化记忆精确可审计，语义记忆捕捉隐性模式。

自适应 Prompt 系统在每次对话前构建上下文注入。LLM 分析器从用户对话历史中检测学习风格、回复偏好和认知状态，生成指令注入 system prompt。规则引擎作为 fallback，覆盖公式推导偏好、视觉学习倾向、深度提问模式等 8 种典型模式。同一个学生两次打开小宇，小宇的话术和策略已经在变化。

MUTAR 自进化引擎运行在这一层。每次对话结束后，系统自动采集完整轨迹，包括工具调用序列、返回结果、用户反馈信号。每周定时分析工具调用成功率、对话完成度和 prompt variant 之间的效果差异，生成优化候选存入 Redis 等待人工审核。不自动应用任何改动。MUTAR 替代的是人不擅长做的大规模系统性排查，人在关键决策点保持最终控制。

**第三层：教育闭环。** 这一层承载完整的教学逻辑。教、练、测、评四个环节构成闭环：评测结果回流至记忆系统更新模型参数，模型变化影响下一次练习的题目选择和复习时机。学生使用越久，系统建模越准，教学干预越精确。

四个环节各有其底层理论支撑。教的环节基于知识树检索和资源推荐，将课程视频、文章和题目挂载至知识节点。练的环节由 Memorix 驱动主动抽题和到期复习调度。测的环节覆盖诊断测试、模拟考试和教师发布的正式考试。评的环节包含自动批改、错因分类和掌握度分析。

4-Agent ARC 出题管线位于这一层。四个 Agent 接力完成出题流程：Author 生成题目，Reviewer 从区分度、清晰度、知识覆盖度三个维度评分，AuthorRevise 根据审阅意见修改，Classifier 做最终审计。管线将单次 LLM 出题通过率从约 60% 提升至 85% 以上。模型能力相近的情况下，架构决定结果。

**第四层：测评引擎。** 这一层解决"如何科学衡量学生能力和题目质量"的问题。

UniMind 采用项目反应理论的三参数 Logistic 模型，这是心理测量学领域经过数十年验证的标准化框架，广泛应用于 TOEFL、GRE、PISA 等大规模考试。IRT 的核心优势在于参数不变性：学生的能力估计不依赖于具体做了哪些题，题目的难度估计不依赖于被哪些学生做过。

机构级参数隔离是 UniMind 的 IRT 实现的关键特征。同一道题在不同机构拥有独立的区分度、难度和猜测参数，采用 MML-EM 参数估计方法输出 θ 能力值。这意味着重点中学和普通中学的学生各自在其机构同龄人中评估相对位置，不会因为机构整体水平差异而失真。Fallback CTT 保证新题冷启动期间的可用性。

变式题匹配引擎与错因分类联动。学生做错后自动检索同知识点相近难度题目插入下次复习队列，概念错误匹配讲解型变式，计算失误匹配练习型变式。

四条架构原则贯穿四层。Memorix 是闭环的节拍器，任何上层代码无法绕过它直接修改复习时间。跨层调用通过 MemorySystem 统一接口，各层可独立进化。新增 Agent 自动继承四层能力。教师控制权是硬约束，难度设定和选题决策属于教师判断域，AI 不越界。

## 二、AI Agent

UniMind 部署两个自治 Agent，共享同一运行时。

**小宇**是学生端唯一 AI 入口。每次对话自动拉取学习统计、知识掌握图谱、到期复习列表和考试历史，综合分析后主动给出判断。学生可以用自然语言完成所有学习活动：查看学习情况、练习薄弱知识点、制定复习计划、了解错题原因、参加诊断测试。

小宇拥有 30 多项工具能力，覆盖知识树检索、学习统计概览、掌握度图谱、到期复习调度、学习计划管理、错题分析、题目批改、诊断测试、课程和文章搜索、答疑工单创建、可视化渲染等。工具执行过程逐步可见，学生随时知道 Agent 在做什么。历史会话可随时切换继续。跨会话记忆让小宇持续积累对学生的理解，包括长期目标和学习风格偏好，每次对话都在变得更精准。

**工作台**是教师端唯一 AI 入口。教师通过自然语言完成全部教学管理：搜索知识点并出题、启动 ARC 精修管线、查看题库统计、布置和批改作业、查询学情数据、管理班级运营。

工作台拥有 20 多项工具能力，覆盖知识点搜索、快速出题、ARC 管线启动和进度查询、题库统计、学生详情查询、作业布置与批改、班级成绩分析、通知发送、课程和文章浏览。同样的多步可见机制让教师实时看到出题和批改进度。工具执行逐步呈现，消除等待焦虑。

两个 Agent 通过 BotRegistry 统一注册和调度。每个 Agent 只需定义工具集、编写系统提示词、注册一行配置。意图路由器按教师或学生的消息关键词预筛选工具子集，从完整工具集中精准定位场景所需的 5 到 8 个候选工具。意图预筛选不只是一个性能优化，它直接影响工具选择的准确率。当 Agent 面对 30 多项工具时，即使模型能力足够，上下文窗口和注意力分散也会导致选择错误。缩小候选范围是提升首次选择准确率的最有效手段。

通信层支持三种传输方式。小宇使用 SSE 流式传输，复用 HTTP 基础设施，学生端延迟敏感度较低。工作台使用 WebSocket 持久连接，教师端需要实时状态同步。通用对话保留 HTTP Polling 作为 fallback。三条路径共用同一个流式引擎，捕获工具调用事件并推送到前端。

## 三、Memorix 记忆调度

Memorix 是 UniMind 的核心算法引擎，解决"何时复习最有效"这个问题。

传统间隔重复算法将每个知识点视为独立记忆单元，各自维护独立的遗忘曲线。这忽略了一个基本事实：知识是一张连通图。练习分部积分时，不定积分的计算技巧在过程中被真实调用，产生可测量的跨知识点迁移。当前最优的 FSRS 算法不具备捕捉这种迁移的机制。它会在学生的不定积分能力已经通过侧向迁移得到提升后，继续安排本不需要的复习。

Memorix 的核心创新是图扩散状态估计器。系统为每个学生维护知识点激活向量，当学生对某个知识点完成成功复习后，激活变化沿知识图谱的拉普拉斯算子传播到相邻节点。被复习节点的激活升高，通过图边在邻居节点上形成梯度扩散。调度器因此能感知到实际发生的迁移效应，将有限的复习预算重新分配给真正需要加强的知识点。在 300 名学生、150 天、215 知识点 CFA 知识图谱的受控仿真中，Memorix 相较 FSRS 实现 5.8% 的留存率提升。消融实验确认整个优势来自扩散机制，关闭扩散追踪器后性能跌至 FSRS 以下 2.4%。

生产部署中分三层运行。扩散状态估计器存储每位学生的激活向量于 Redis，每次成功复习即时传播激活，每日全局扩散更新。乘法评分层在选课环节结合自需紧急性与邻居影响力。机构级自动调参层按周扰动参数，接受改进、回退劣化，8 周全周期收敛。参数按机构隔离，冲刺班的最优参数不适用于大学场景。

在遗忘建模层面，Memorix 使用 Weibull 分布的形状参数从数据中学习。在线 SGD 加 Nesterov 动量实现逐次答题实时参数更新，新用户从人群均值出发逐步漂移到个性化最优。Brier Score 严格恰当评分规则确保预测概率收敛到真实概率。Memorix 输出的 0.8 真的对应 80% 的回忆率。

## 四、知识图谱

体系化知识管理是 UniMind 区别于碎片化刷题工具的根本特征。

系统内置 13 个学科的全景知识图谱：金融 431、CFA、CPA、法考、法学、教资、教育学 311、计算机 408、高中数学、高中物理、高中化学、高中生物、USMLE。四级树状结构从学科展开到篇章、小节、考点，总计 4,486 个知识点。每个知识点关联对应的题目、课程视频和学术文章。

知识图谱不只是浏览工具。它是 Memorix 图扩散的骨架，相邻知识点之间的边权决定激活传播的幅度。知识嵌入向量从知识点共现矩阵通过 PCA 初始化，图结构直接参与调度算法的计算。这意味着图谱的质量直接影响记忆模型的预测精度。

机构可导入自定义知识树，通过 Markdown 格式描述层级结构，完全替换全局默认。AI 也可根据学科名称自动生成知识树。这种可替换性意味着 UniMind 不绑定任何特定学科或考试，机构将自己的教学体系映射到系统中。

## 五、使用场景

UniMind 的 Agent 驱动架构决定了使用方式：学生和教师通过对话完成全部操作，不依赖菜单导航。

一个典型的学生学习周期从诊断测试开始。新用户首次登录后，系统用 10 道题评估知识水平，根据结果初始化个人 Memorix 参数。之后小宇持续监控每个知识点的记忆状态。当检测到某个知识点即将被遗忘，系统在后台触发通知推送。学生打开 UniMind 时，小宇已经在对话中给出具体建议：需要复习哪些题目，上次的正确率是多少，今天建议从哪个薄弱点开始。学生回应一句话即可开始练习。做错的题目自动归类错因，匹配变式题插入复习队列。整个过程不需要点击任何功能菜单。

教师的工作流同样通过对话完成。打开工作台，用自然语言描述出题需求。Agent 搜索知识点、生成题目、展示结果。教师确认质量后一句话入库或布置给学生。ARC 管线对需要精修的题目进行四 Agent 对抗优化，实时展示进度。第二天查询作业提交情况，一键 AI 批改主观题，复核后发布成绩。班级的薄弱知识点分布和学习趋势通过自然语言即时查询，不需要学习任何数据平台的操作。

新机构从注册到学生开始使用，全程不超过一个工作日。选择学科模板，创建班级，邀请教师和学生加入。14 天全功能试用期间，机构可评估效果后决定付费方案。

## 六、自进化机制

软件系统的质量通常依赖人工排查和迭代。当系统规模增长到 30 多项工具、多个 prompt 模板、多种模型路由策略时，人工排查变得不现实。MUTAR 引擎解决这个问题。

MUTAR 的五阶段闭环运行在 ARCA 架构之上。Measure 阶段实时采集每次 Agent 对话的完整轨迹，包括工具调用序列、返回结果和轮次数。Umpire 阶段按周评估工具调用成功率、对话完成度和 prompt variant 之间的效果差异。Think 阶段分析差异根因，定位参数调整需求、模板质量变化和工具选择偏差。Adapt 阶段生成优化变体，存入 Redis 等待人工审核。Refine 阶段在人工确认后部署生效，成为下一轮采集的基线。

整个过程自动运行，但所有实质性改动保留在人的控制之下。MUTAR 替代的是人不擅长做的大规模系统性排查，而非替代人的判断。系统在生产环境中持续发现自身弱点并生成改进方案，人在关键决策点保持最终控制。当前数据采集到分析的全链路已打通，优化执行层等待轨迹数据积累后开启。

## 七、数据安全与部署

机构间数据独立存储是 UniMind 安全架构的基础。每家机构的学生记忆模型、IRT 参数、知识图谱和 Agent 对话历史均独立隔离，不同机构的数据互不可见。

认证以 httpOnly cookie 为主，配合 CSRF 保护，避免 XSS 窃取令牌。四层 RBAC 角色体系覆盖超管、机构主、教师和学生，叠加按定价方案的功能权限控制。敏感字段通过 Fernet AES 加密存储。审计日志完整可追溯。

AI 引擎设置按任务类型粒度的熔断保护，单模型故障不会扩散。所有 AI 调用经过工具权限白名单审计，Agent 无法越权操作。

部署方式分两种。SaaS 云服务注册即用，30 秒完成初始化，无需运维。Pro 方案支持完整私有化部署至机构自有服务器，数据不出内网。机构拥有全部数据的所有权和导出权。

## 八、技术概要

后端基于 Django 6.0，异步任务通过 Celery 和 Redis 调度，实时通信以 Django Channels 和 Daphne 支持 WebSocket 与 SSE 流式传输。

AI 引擎采用 DeepSeek V4，按任务类型分级路由。对话和面试等快速响应场景走 fast 模型。出题生成配合 structured output 保证格式可靠。出题审查是唯一显式开启深度思考的任务。批量出题和主观题判分走 pro 模型。按任务粒度的熔断保护确保单模型故障不会扩散。

前端基于 React 19 TypeScript，使用 Tailwind CSS 4、shadcn/ui 组件库、Zustand 状态管理、KaTeX 数学渲染、Recharts 图表。国际化支持中英双语。数据库采用 PostgreSQL，开发环境可用 SQLite。部署基于 systemd 和 Nginx，支持单机与分布式扩展。
