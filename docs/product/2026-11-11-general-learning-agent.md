# 通用学习任务与教学接续

这是个人目标学习第五期的评审增量，基于第四期 `9250293`，依赖尚未合并的 #29 和 #26。函数仅为案例；当前实现未发布，不能据此声称全部学科已有成熟内容或教学效果已验证。

## 实际行为

- 普通阶段计划可直接准备任务，不要求先建知识地图。支持授权题库题目和本人项目原创任务，两者择一。
- 原创任务包含问题、成果类型和公开标准；接收解释、计算、推理、案例或代码文本。参考解答在完成评分前隐藏，代码仅作文本评价，未经执行。
- 沿用正式提交、异步评分、失败重试和逐题复盘。`task_id = practice_id = submission_id`；原创任务不进入公共题库，不计入题库 Memorix 或 ELO。
- 记录起点检查、练习、复测及其原任务关系。补救可安排到同项目、同知识版本的其他计划阶段；复测仍需同知识单元并更换题干。
- 项目接续区分未做、评分中、系统失败、存在缺口、有提示完成与不同任务的独立支持观察。较新的实际对话反馈可调整建议；创建任务本身不算新表现。
- 小宇通过实际运行时读取原作答和评价，再保存关联任务。服务器生成的任务卡片仅接受确切站内任务链接，打开后重新校验本人权限。

主观评分标注 `model_rubric_grade`，属于模型参考评价，未独立复核。存在知识地图时才形成节点证据；同题、跨节点和不同帮助条件分别处理。BEP 的固定参数仍未校准，推进教学建议不自动判定掌握或结束目标。
