# 当前对话内动态工具注册原型

状态：本地实现，沿用 `UNIMIND_LEARNING_EXPERIMENTS_PROTOTYPE=true` 与 `DEBUG=true`，默认关闭，未部署生产。真实浏览器 Worker、DSH SDK 与本机模型协议冒烟通过；2026-11-08 真实 DeepSeek 在空白合成对话中完成编写、自纠错、注册、新工具调用和最终回答，结果经独立计算核对一致。该条完整流程验收通过，不代表所有任务稳定性或教学效果已经验证。

## 实现的行为

模型可以编写一段计算逻辑，连同名称、说明、参数 Schema 和自检样例交给 `register_session_tool`。通过自检后，平台把它加入当前对话的工具列表。下一次模型请求即可直接调用新名称，例如 `session_bond_price`；无需再通过一个通用执行工具转发参数。

模型下一轮仍可调用该工具。修改时先用 `read_session_tool` 读取代码与版本，再沿用名称、带 `base_revision` 注册新版本。失败的更新保留旧代码和旧参数结构。

名称只是示例，不含预置债券公式。源码由模型提供，入口约定为 `function run(input)`，也支持异步函数，返回 JSON 数据。

典型过程：

```text
提出学习任务
→ 模型编写 run(input) 与参数 Schema
→ register_session_tool 自检并保存
→ 下一次模型请求出现 session_xxx
→ 模型直接调用 session_xxx
→ 根据真实计算结果回答
```

可以先用这样的合成问题手动验收：“为这次讨论写一个债券价格计算工具，注册后计算面值 100、年付息 4、期限 10 年、收益率 6.7% 的价格；之后换一组参数继续使用。”这段提问尚未发往外部模型。

## 作用范围

- 只向有小宇学习工具权限的课程学员和管理员开放。
- 工具归当前账号和当前对话所有，放在该对话首条用户消息的 `session_tools` 元数据中，随对话消息清理，无新增数据表。
- 名称须匹配 `session_` 前缀，无法替换已有平台工具。每个对话最多 6 个工具。
- 注册成功后刷新当前执行器的模型可见列表、许可 Schema 和版本映射；同一轮即可在注册返回后调用。注册与第一次调用应分成两轮工具请求，不能在注册返回前猜测调用。
- 后续聊天入口重新装载已注册名称。每次调用重新检查当前权限、对话归属、当前版本和完整参数约束。旧执行器不会静默执行另一个轮次更新后的版本。
- 只处理显式 JSON 参数，不授予课程、笔记、成绩、文件或其他业务 API 的读取与写入权限。

## 运行边界

生成代码在短时独立浏览器 Worker 中执行，`document`、`window` 不可用。Worker 位于隔离 iframe，CSP 禁止联网，预览浏览器也拦截网络请求；进程环境没有模型或站点凭据。

每次调用使用新 Worker，函数不保留隐藏的运行状态。单个 Worker 最多约 1.2 秒，整个运行子进程最多 12 秒，超时终止进程组。仍是本地原型，没有完成公开服务所需的并发与内存资源隔离验收。

源码最多 12000 字符；参数 Schema 最多 4 KiB，只支持三层以内的 JSON 基础类型、属性、数组、枚举和范围约束。对象参数必须设置 `additionalProperties=false`。调用输入最多 4 KiB、输出最多 8 KiB，拒绝非有限数值及无法序列化的数据。

注册需要 1 至 5 个样例。数字按绝对误差 `1e-6`、相对误差 `1e-9` 比较，结构和其他值严格比较。自检只验证给出的输入输出，不代表公式对全部输入正确；模型仍可能同时写错代码和期望值。

## 与 DSH 的关系

2026-11-08 已接入现有 DSH 插件：后端使用签名任务中的账号、对话和当前消息绑定注册表；插件通过 `ctx.tools.register` 暴露通过检查的函数。注册或读取成功后，在下一次系统提示组装时替换可见工具组。

`authoring` 分组提供实验编写、实验读取、函数注册和函数读取；`session` 分组提供函数读取和最多 6 个已注册函数。加上发现工具，每次最多 8 个模型可见工具。注册源码不作为 TypeScript 插件装载，继续在原隔离浏览器 Worker 中运行。

网关在每次模型请求前向已认证后端重新读取该对话的注册表，核对账号、权限、记忆版本和模型预算。新函数名必须真实存在，参数 Schema 必须与后端一致，不接受仅凭 `session_` 前缀声明的工具。调用另带版本号，缺失、过期或跨对话均拒绝。注册表变化不触发账号权限指纹变化；实际权限、记忆与原型开关变化仍会阻止继续执行。

同时开启 DSH 小宇入口与本地原型时，原型通过 DSH 执行；未开启 DSH 时继续使用原流式引擎。DSH 实验卡片复用已有隔离渲染器和状态接口。只有已授权的本地原型任务使用 `assistant.chat.planner.prototype` 预算，当前每轮最多 6 次模型请求、每次最多 8192 输出 token；普通 DSH 聊天仍为 4 次、1024 token。原型开关默认关闭，且仍要求 DEBUG。

新增 6 项本机定向冒烟通过：2 项后端/原生 DSH 验证、2 项网关验证、2 项卡片验证。原生验证使用缓存中锁定的 `deepseek-harness-sdk==0.2.1rc2`、真实 Django 签名回调、真实浏览器 Worker 和实验预览；本机模型协议样例依次触发发现、注册与实验生成、新名称调用、最终回答，共 4 次本机模型请求。确认下一次请求出现 `session_product`、调用结果为 42、实验卡片进入会话，并完成网关用量结算。另验证未知名称、伪造 Schema、撤销注册表、过期版本、其他对话和关闭开关时拒绝调用。DSH TypeScript、前端 TypeScript、Django 系统检查通过。

上述新增验证没有调用外部模型 API，未使用真实学生记录，未部署生产。真实模型能否自主判断、编写并注册合适的函数仍待验收，不据此声称教学有效性或模型权重发生改进。

## 同日复现与修复

用户再次授权最多 4 次排查请求。本批先使用 3 次复现，保留了 `tool-callbacks.jsonl` 和逐条 SDK 事件：

1. 模型生成的债券函数正常执行，目标例实际返回价格 `66.52648421676233`、修正久期 `8.362464741973204`，独立 Python 求和与之相符；模型自检却写成 `66.0160030377`、`8.8104155645`。另一个三年期例子的久期期望值也错误。
2. 函数返回 `price`、`modified_duration`、`macaulay_duration`、`coupon_years` 四个字段，自检只给了前两个。对象结构严格比较，因此即使数值正确的单期与零息例子也会拒绝注册。规则本身保持不变，工具说明和提示词现已明确要求完整返回结构。
3. DSH 的工具结果包含完整自检反馈，没有截去实际值。模型随后修复时已改对数值，但参数字符串出现 `"tests" string="false">`，不再是合法 JSON。SDK 以 `MALFORMED_RESPONSE` 结束，修复内容未到达后端。保留的参数字符串可在本地稳定复现 JSON 解码失败。
4. Host 先判断没有最终文本，再检查结束原因，掩盖了 SDK 的具体失败。已调整判断顺序，对该错误返回“模型生成的工具参数不是有效 JSON”，不再笼统报没有回答。通过离线回放结束事件，先复现原错误，再验证修复；另跑一项原成功流程冒烟，两项均通过。

最后使用本批剩余 1 次请求，把捕获的反馈交给模型，并使用补清后的工具定义与提示词。模型保留原计算公式，只返回任务需要的两个字段，修正四组自检期望值；四组均通过，`session_bond_price` 在真实 DSH 回调中注册成功。随后本地直接调用返回价格 `66.52648421676233`、修正久期 `8.362464741973204`，独立核对通过。该次网关只允许 1 个模型请求，不足以让模型再发起下一轮调用或最终回答，因此不把这一结果记为完整自主流程通过。

本批合计 `3 + 1 = 4` 次官方请求，无超额。新增一项本地债券诊断冒烟覆盖错误小数、遗漏字段、修正后的注册与直接调用，通过；没有放宽数值误差或字段比较。完整产物分置于 `dsh-session-tool-diagnosis`、`dsh-session-tool-repair`。没有修改平台预置债券公式、替模型手写修复源码、部署或使用真实学生数据。首轮缺失的原始输入无法追溯，不将本次复现等同于对首轮每次尝试的逐一还原。
