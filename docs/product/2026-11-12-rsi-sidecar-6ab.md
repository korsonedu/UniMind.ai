# RSI sidecar 6A＋6B

本期把 RSI 作为 DSH 的长期旁路模块：在线只追加版本、方法使用、工具依赖、教学暴露和明确关联的后续任务记录；后台由显式命令产生 G/E 影子版本和比较报告。不新增前端侧栏，不替换现行教学，不开启旧全量 beat，不自动晋级、随机分配或部署。

## 6A：可追溯的教学记录

机制基线 G/S/E/M 的代码、提示来源与模型标识留存为 hash；M 当前仅保留尚未运行的版本描述。每轮冻结版本与学习快照，重试复用。当前选择仍为模型主导的非随机选择，propensity 为空，不能倒填成随机概率。

方法正文单独保留版本，方法使用的原分配与实际回复完成分别记录。回复已完成不表示已确认按方法执行。任务通过显式 `strategy_use_id` 绑定，不按同用户或相近知识点推定采用。结果保留评分来源、帮助、时间和重复检查，不自动写支持、掌握或因果收益。来源撤回及当前权限继续校验。

## 6B：独立的影子研究

```sh
python manage.py research_teaching_mechanisms --project PROJECT_ID --kind G \
  --packet ai_assistant/tests/fixtures/rsi_shadow_synthetic.json \
  --output /private/tmp/rsi-g-fixture.json
```

默认只允许明确合成 fixture，不调用模型；预设输出不能冒充真实模型结果。加 `--live-model` 才会调用当前配置模型，先基于开发材料提出 G1/E1，再比较两臂：

- G：两份生成指令作用于相同冻结案例；使用同一固定评估器，报告其质量代理。
- E：两份评价指令作用于同一批冻结成果，记录各自判断。

两臂使用相同调用上限和单次输出上限。候选提案记入候选臂预算；实际调用、token usage、耗时、失败和未知用量分别保留。上限相同不表示实际计算成本相等，模型供应商权重也未固定。配置的model与响应实际返回的model分别记录；DSH协议fixture不能标记为live model。成功响应的usage只有prompt/completion/total均为非负整数才算完整，隐式重试用量未知时provider总用量完整性保持false。超预算或调用失败会标记 incomplete/limited，没有自动胜出者。

packet 的顶层字段为 `schema_version/provenance/development/cases/baseline/fixture_candidate/fixture_outputs/budget/anchors/protocol`。案例只允许明确的题目、原作答、标准、帮助和来源字段，不能把期望分数混入案例字段。实际材料只接受属于当前项目的任务引用，并重取冻结作答、选项、参考答案、完整标准及当前权限；帮助、重复和暴露依据不足时标为unknown，不能换case编号重复计同一任务或结果；fixture 仅为显式合成材料。

作答分数锚点仅接受E，G的方法质量不与作答分数混比。锚点独立存放，既不进入候选提案，也不进入两臂模型输入。现阶段命令接受的人工声明或来源说明没有独立签署核验，始终标为 `operator_supplied_not_attested`。即使模型与声明标签一致，也只记录代理指标，完整运行仍为 `awaiting_independent_anchors`，不成为 eligible。没有真实独立后测，不能证明教学增益、评分可靠性或递归改进。

G0/E0 是操作员提供的私有影子起点，谱系指向代码基线；不冒充当前线上完整教学规则。候选归项目所有者，输出文件为 0600，不覆盖已有文件。报告可能包含本人材料衍生内容，不能直接公开。运行不写公共题库、正式成绩、BEP 参数或生效指针。

## 完成范围

本期交付是证据/版本链和可运行的 G/E 影子研究。三类合成案例覆盖数学、计算机原理和题内虚构规则，只验证通用适配与流程。独立人工锚点、真实学习效果、贝叶斯选择器和 M 的递归优化属于后续阶段。数据库迁移、CI、定向冒烟与本地真实模型运行结果由本次实施验收记录另行登记；实现不等于已上线。
